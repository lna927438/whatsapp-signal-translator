# HelloDog 0.5.0

HelloDog replaces the previous Realtime Translator product branding. The Windows application ID and existing user data paths remain compatible with installed releases.

## User-visible changes

- A new dog and speech-bubble icon, warm ivory and forest-green visual theme, website, download page, sign-in screen and desktop workspace.
- Collapsible sidebar with Ctrl+B, account search and keyboard-accessible account menus.
- Native context menus for back/forward, reload, copy/paste, current URL, rename, translation visibility, WhatsApp zoom, diagnostics, logs, workspace navigation and confirmed removal.
- Native WhatsApp bounds follow the actual content area, including sidebar, toolbar wrapping, window resizing and application zoom.
- Font size, translation color and translation visibility apply to existing messages. Signal uses the same visibility setting.
- Automatic, primary and backup translation routes, with measured health latency. Transport retries preserve request IDs, input and task identity; application authorization and billing errors are not retried through a different route.
- Separate non-billable connection diagnostics from explicit translation tests. A reachable model does not claim that inference or billing succeeds.
- Download metadata timeout/retry, immutable version links, full SHA-256 copy and clear same-source fallback. Existing latest installer URL remains compatible; new versioned installers use the HelloDog name.
- Website examples are explicitly prewritten examples with selectable scenarios, never presented as arbitrary live translation.

## Verification

- 63 local regression tests passed, including failover identity, disabled-account behavior, real health response validation, native bounds, legacy data directory selection and translation visibility.
- Desktop typecheck and build passed. Website typecheck and build passed after installing its declared dependencies.
- CI additionally verifies PostgreSQL concurrency and produces the Windows installer.
- No personal chat messages were sent during verification. Actual WhatsApp/Signal device linking and sending still require testing in the user's installed client.
- End-to-end translation requires valid service-side provider credentials; connection diagnostics report credential failures without exposing any key or upstream payload.
