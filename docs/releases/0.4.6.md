# Windows 0.4.6

本次更新落实客户端的三项优先改进：

- 发送可靠性：翻译前保存原文、目标语言、上下文和请求编号；重试或重启后沿用同一任务。发送后没有确认的任务需要先在原对话核对，不自动重发。确认未发出后可继续使用已有译文。
- 弱网体验：Signal 草稿按登录用户、账号和收件人保存，旧请求完成不会覆盖新草稿；余额失败显示“未同步”或上次确认的余额；查询合并、超时和自动翻译重试有上限。
- 登录稳定性：同一用户刷新令牌保留工作台；换用户或退出时阻止旧任务继续发送；记住登录选项生效；退出只处理当前设备的在线会话。

WhatsApp 在提交前核对当前对话、编辑框和文本；只有发现新出现的对应发出消息才报告进入发送队列，输入框清空不再单独视为发送成功。Signal 对返回结果与同步事件去重。发送前通过现有 API 再检查在线账户状态。

尚未发出的任务可以取消；再次发送会使用当前设置建立新任务。取消不会撤销已经完成的翻译计费。结果不确定的任务不能直接取消，必须先核对发送结果。

## 验证与试用

回归测试覆盖持久任务重试、并发去重、发送不确定性、账号隔离、停用账户、令牌刷新、旧会话返回、草稿保护、余额同步和 WhatsApp DOM 发送守卫。Windows CI 类型检查和构建、现有 PostgreSQL 并发测试、R2 完整文件校验作为发布验证。

真实 WhatsApp/Signal 网络与 Windows 桌面仍需用户试用确认。自动化使用模拟消息和模拟翻译接口，不向真实联系人发消息。建议依次测试：

1. 发一条短消息，核对收件人、原文、译文及余额变化。
2. 连续按发送；翻译等待时切换对话或编辑新草稿，确认没有错发或覆盖。
3. 断网后恢复、退出再登录、关闭重开，核对任务和草稿恢复。
4. 遇到“发送结果未确认”时，先在手机原对话核对，再选择已发送或未发送。

任务保存依赖本机应用数据目录；请勿在排查期间删除该目录。WhatsApp 消息结构发生变化时可能无法获得界面确认，此时会保守显示“发送结果未确认”。
