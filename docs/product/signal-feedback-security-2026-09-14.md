## 原因与修复

| 用户遇到的问题 | 查到的原因 | 本轮修改 |
| --- | --- | --- |
| Signal 部分历史消息、带表情的文字不翻译 | 界面把失败的消息永久记为“已尝试”，错误被忽略；同步桥接异常还可能占住翻译队列。手动翻译传递整个响应式消息对象，会触发 `An object could not be cloned.` | 仅传递账号、对话、时间、方向四个原始字段；失败后限次退避重试，恢复网络及刷新可恢复；直接处理返回译文。保留纯表情无需翻译的规则。 |
| 照片不能右键复制、保存体验不可靠 | 旧媒体组件没有右键菜单；附件缺少文件名时没有图片扩展名；升级后的 Electron 使用异步剪贴板接口 | 新增右键复制、保存和大图工具栏；等待剪贴板真正写入再显示成功；按媒体格式补充文件名后缀，取消保存不报成功，保留原文件字节。 |
| “媒体、链接和文件”只显示附件文字列表 | 旧详情页没有图片网格和连续查看器 | 分为媒体、链接、文件三个标签；图片与视频按月份展示缩略图，按需读取、分批显示；支持前后切换、复制、保存及键盘操作。 |
| 右键后 Esc 不关闭大图 | 焦点可能离开图片面板，面板收不到按键 | 大图打开期间接管对应键盘操作，关闭时释放监听并恢复焦点。 |
| 较窄窗口媒体栏覆盖聊天 | 原详情页在 1100 像素以下直接覆盖右侧聊天 | 常用桌面宽度下使用 300 像素并排栏；更窄窗口切换整个详情视图。980 和 1360 像素窗口已验证媒体栏不覆盖聊天。 |

新的图片操作仍从保存的消息中查找附件，拒绝错误账号、错误对话、子框架、已经过期或切换登录身份的请求。图片访问地址不暴露磁盘路径，不能由界面指定任意磁盘文件。复制接口按当前 [Electron 官方文档](https://www.electronjs.org/docs/latest/api/clipboard) 使用 ClipboardItem 和异步写入。
