## 本轮完成

1. 用户列表、账号启停、钱包、设备登记、字符流水读取真实云端数据。列表和费用页每 5 秒刷新；客户端原有钱包轮询约 5 秒。
2. 「添加字符」填入正整数即可提交，备注可选。服务端按增量在事务中更新钱包和流水；正在翻译产生的余额变化不会阻止正常添加。
3. 每次添加有独立操作编号。断网或返回结果丢失时查询原操作，重复提交同一编号不会再次增加余额。
4. 管理界面收起套餐、支付、版本、公告及多管理员授权入口，保留用户、翻译、费用、操作记录和管理员账号。
5. 数据库明确绑定唯一管理员身份。普通账号不能调用管理接口，不能通过个人资料声明管理角色；不能新增、替换或移除该管理员。
6. 客户端 `/api/me` 读取时记录最近联机时间，30 秒内合并更新。近两分钟联机仅表示客户端访问过 HelloDog 服务，不能当成 WhatsApp/Signal 当前在线状态。设备登记时间单独保留。

## 字符、Tokens 和美元成本

- 字符额度仍按原文 Unicode 字符数扣减；不使用固定字符/Token 比例计算 API 成本。
- 新翻译在取得唯一请求处理权时预登记用量行，随后保存实际 API 的响应编号、请求编号、模型、输入 Tokens、缓存命中 Tokens、输出 Tokens、总 Tokens和推理 Tokens。
- 只保存上述用量数据，管理接口不返回聊天原文、译文、密钥或完整供应商响应。
- API 费用 =（未缓存输入 Tokens × 未缓存输入单价 + 缓存输入 Tokens × 缓存输入单价 + 输出 Tokens × 输出单价）÷ 1,000,000。
- 推理 Tokens 是输出 Tokens 的子集，不重复计价。提示词、上下文等供应商实际计算的用量全部包含在 API 统计里。
- 官方美元单价核验来源：https://api-docs.deepseek.com/quick_start/pricing/ 。当前保存单价版本 `deepseek-usd-2026-09-12`，逐请求保留当时单价和时段。
- DeepSeek Flash 每百万 Tokens 空闲价为：缓存输入 USD 0.003，未缓存输入 USD 0.15，输出 USD 0.60。高峰价格为两倍。
- 高峰为周一至周五 UTC 01:00–04:00、06:00–10:00，即北京时间 09:00–12:00、14:00–18:00。优先采用 API 返回的创建时间；没有该时间时，仅在整个请求处于同一价格时段时核算。
- API 成功产生用量、但译文校验失败或用户未被扣字符时，也保留供应商成本。超时、回执缺失、模型单价未知分别显示未核算，不冒充零费用。
- 每百万字符的成本由同一批已核算且扣字符的请求汇总换算，是成本统计，不是套餐售价。
- 官网单价将来变更时，需要增加新的单价版本；本轮没有创建自动抓取价格的任务。

## 官方账单核对

费用页提供按 GMT+8 日期、API 服务统计，以及用户和日期汇总。

「查询官方余额」使用现有 DeepSeek Key 调用官方只读 `/user/balance`，显示官方返回币种、充值余额和赠金。该接口不提供逐请求账期账单，余额变化不能直接认定为翻译消费。

「核对官方账单」录入官方导出的账期金额、请求数、总 Tokens 和来源，保存不可变核对快照。缺少请求明细时标为不完整，不计算貌似精确的差额；完整数据才能与官方金额和数量比较。核对结果保留在操作记录。

本轮接入时：真实库有 3 位用户、238 条成功翻译用量记录，合计扣减 7,017 字符；包含失败处理在内共有 251 条云端请求。旧记录没有保存 Token 明细，不能精确补算费用。接入后首次验收时新用量表仍为 0 行，尚未收到新的真实翻译；没有把测试数据写成真实消耗。
