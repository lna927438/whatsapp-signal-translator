# HelloDog 0.5.3-rc.2

2026-09-12。本地发布候选版，尚未替换正式下载。套餐、定价和支付不在本轮范围。

## 修复

- WhatsApp 新版消息没有旧的发送方向标记时，识别原生尾标、本人标签和已读标记。引用消息里的标记不能作为本条消息的发送证据。
- WhatsApp 连续发送优先通过原生 Lexical 编辑器同步交接文本，避免多次异步选择和清空造成吞回车或草稿拼接。后台发送等候短暂的输入停顿；上一条草稿保存未结束时也能接收下一条发送意图。
- WhatsApp 按已经确认的原生消息编号和正文恢复原文，在缓存读取和付费请求入口各检查一次。重绘时缺少方向标记不会让已发送的译文再扣一次翻译费用。其他消息即使文字相同，仍独立处理。
- Signal 尚未发出的原文不能被接收翻译再次处理。已经发送的历史消息、手机同步消息和保存的原文注释保持原有行为。
- 保留 rc.1 的中英文界面、齿轮设置、一键重启、紧凑图标栏、WhatsApp 可调整会话列表、历史与草稿恢复、独立账号数据和官方 Signal 媒体流程。

## 本机和真实账号检查

- WhatsApp：真实自发连续 20 条，20 个原生消息编号，20 笔扣费，共 579 字符。每条原文注释只有一份，未留下待确认发送；包括两条文字相同的独立消息。
- Signal：真实自发连续 20 条，20 笔扣费，共 548 字符，没有额外的接收翻译请求；包括两条文字相同的独立消息。
- WhatsApp 原有误判消息在恢复后确认已发，刷新后原文恢复、余额不变。
- Signal 图片、表情附言、文件、音频、视频和 GIF 经自发流程验证；测试音频和视频成功解码并播放。刷新保留中文与表情草稿，没有误发或新增扣费。
- 本机已通过正式安装程序从 0.5.3-beta.2 更新到本版，旧程序保留备份。原登录与两个账号保留，WhatsApp 升级后原文恢复且未新增扣费，Signal 原生聊天窗口可打开并刷新，关闭主窗口仍保持后台运行。
- 本轮实测发现的 22 笔多余翻译费用，共 705 字符，已通过管理员逐笔补偿，保留原始扣费记录。4 个先前本机待确认请求在云端未找到扣费，没有重新提交。

这些是单个自有账号的实际自发测试，不能代表另一端收到消息或真实通话。连续测试的总耗时包含自动化操作、显示检查和对账，不能作为纯输入延迟或产品性能承诺。
