# HelloDog 0.5.7

客户端右下角新增版本和管理员消息提醒，并增加消息中心。管理员可从官网后台的「客户端通知」发送给全部用户或指定登录邮箱，预览内容、安排时间、设置有效期及停用通知。用户详情中也提供「发送通知」。套餐与支付保持原状。

提醒以独立子窗口显示，避开底部输入区域，不取得键盘焦点，不新增任务栏图标。主窗口最小化、隐藏、失去焦点或打开设置等覆盖面板时暂停显示。提醒约 12 秒后收起，鼠标停留时延长。每位登录用户、每条通知版本只自动展示一次，本机 5 分钟最多展示 3 条；用户仍可从消息中心查看有效通知。编辑已发送通知生成新修订，旧回执不计入新修订。

客户端正常联网时约每 30 秒同步管理员通知，出错后退避重试。版本元数据缓存约 10 分钟，版本弹窗关闭后 24 小时内不重复提醒。离线用户下次联网时收到仍有效的通知。0.5.6 及更早客户端需要升级后才能使用新弹窗，原有版本提醒继续使用。

后台「已弹出」仅计客户端实际绘制并回传的记录，「已确认」仅计用户关闭或点击按钮后的回执，均按用户及通知修订去重。后台保存成功不等于用户已经看到。通知按登录身份在服务端筛选，数据库行权限同样隔离指定用户内容。回执重试幂等，本机仅保存账号 ID、通知 ID、状态及时间，不保存通知正文。

同时包含 0.5.7-beta.1 的 WhatsApp 布局修复：按实际列表边缘定位拖动区，打开已归档页面不会从错误位置覆盖聊天内容，移除聊天区内多余竖线；不支持安全缩放的页面结构使用原生宽度。Signal 内核保持与 0.5.6 一致。

验证证据：verification/notifications-0.5.7/ 下的数据库权限与回执回归、后台浏览器实际保存验收、Electron WebContentsView 原生弹窗与焦点验收、完整回归日志和发布校验记录。测试使用独立数据目录及样例内容，不向真实联系人发送聊天信息。安装程序沿用现有 Windows 未签名发行方式。
