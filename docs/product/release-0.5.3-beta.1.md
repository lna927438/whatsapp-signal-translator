# HelloDog 0.5.3-beta.1 本地修复说明

2026-09-12。本轮仅生成本地测试包，没有部署网站、云端接口、数据库或下载更新。

## 修复

1. **Signal 右键刷新不可用**：此前菜单只获取 WhatsApp 的页面对象，Signal 刷新被禁用。现在按平台刷新；Signal 原生窗口空闲时刷新，有草稿、附件、录音、通话或发送任务时保留现场并检查连接。刷新保存失败会保留原窗口；连续点击合并为一次操作，20 秒未响应则结束等待。
2. **发送持续转圈**：翻译阶段的失败此前进入 Signal 原生网络重试，可能反复等待很久。现在在进入原生上传/发送前保存失败状态，释放该任务。原文和消息编号保留，可通过原生失败消息入口重试。没有新增逐条发送审核。
3. **反向翻译与不必要收费**：对能够较明确识别的普通英文、目标为英语且未请求语气/术语改写的消息直接发送。中文、其他语言、混合内容和不确定内容仍走翻译。这项语言判断是有限规则，后续仍需升级。
4. **目标语言与中文拦截冲突**：中文或日语目标允许汉字；其他目标保留原有拦截行为。错误原因不再全部被替换成“消息保留在发送队列”。
5. **迟到结果与设置**：桥接翻译 45 秒超时后不再等待，迟到结果不会自行发送消息；账号菜单里的显示译文设置立即通知对应 Signal 账号。

- HelloDog 前端与主进程类型检查通过；整个固定版本 Signal 源码类型检查通过；官方组件和 HelloDog 构建通过。
- 实际打包的 Signal 8.27.0 组件，在独立且未关联手机的测试目录中完成刷新响应、重复点击合并、同进程/同目录保留、菜单后窗口恢复及正常退出检查。
- 实际 HelloDog 测试包登录页面启动通过，包含 Signal 组件和窗口辅助程序，页面未捕获到运行错误。
- 未向真实联系人发送消息、拨打电话或修改线上余额。真实收发与通话不能由上述测试代替。

## 本地使用

安装包：`release/v0.5.3-beta.1/HelloDog Setup 0.5.3-beta.1.exe`。

本机安装更新前，先从托盘完整退出旧版。安装更新会沿用本机 HelloDog 的账号目录；不要手动清理账号数据。安装包未做代码签名。

需要完全独立测试时，可运行同目录的 `Start isolated test.cmd`。它使用单独的测试目录，不读取正式账号缓存；需要重新登录并关联测试账号。

对应源码随安装包放在同目录，名称为 `HelloDog-0.5.3-beta.1-corresponding-source.zip`。校验值见 `release-manifest.json`。

## 建议这一轮手测

- 对测试联系人输入一段已经是英文的文字，目标英语；检查原样发送且不产生新的翻译收费。
- 输入中文并快速连发数条，检查顺序、输入框响应及原生回执。
- 对失败消息使用原消息重试，检查没有另建同内容消息或重复翻译收费。
- 带草稿、带待发送图片、空闲时分别右键刷新，检查内容和账号保持。
- 断网后恢复、退出重开，区分待翻译和平台发送结果未知；不要把未读当作发送失败。
