# HelloDog 0.5.17-beta.3 本地显示修复

仅供本地验收，不公开发布，不修改服务器、官网正式客户端版本或 OpenAI 密钥配置。

## 本次修改

- 修复聊天页慢加载阻塞其他窗口切换的问题。选择和布局先完成，网页加载独立进行；旧加载完成后不会抢回当前窗口。
- WhatsApp 在页面 DOM 可用时显示，无需继续等待较慢的附属资源。加载失败或崩溃会显示原因与刷新入口，保留账号资料和已保存草稿。
- 修复崩溃页刷新时仍等待失效页面执行脚本的问题；正常页面刷新继续保护正在发送的消息、附件、录音和音频。
- 客户端界面重新加载后，清除旧界面的窗口选择及隐藏状态，再同步真实内容区域尺寸，避免网页仍藏在已关闭的设置后面。
- 聊天窗口上方增加“刷新当前聊天”按钮，保留 F5 / Ctrl+R；重复点击合并，刷新期间切换窗口不会被抢回。
- 删除“翻译恢复”侧栏入口及旧大面板，只将“版本与更新”保留在设置。翻译任务持久化、自动核对、防重复扣费和发送保护继续运行。
- 设置 → 版本与更新：查看当前版本、检查更新、校验下载及安装；已是最新版时不显示更新按钮。手动检查会重新查询，检查失败不会误报最新版。
- 侧栏和设置中加入重启、官网入口。重启先保存设置、草稿及原任务；健康页面保存失败或音频仍在使用时，不会强行退出。
- 暂停的窗口可直接恢复，不再依赖旧“翻译恢复”面板。

## 本地使用

1. 保存所需资料，从旧版 HelloDog「文件 → 退出」正常退出。
2. 安装本地 beta.3 包，保留原安装路径及账号资料。不要同时运行两版共享账号目录。
3. 打开已有 WhatsApp 窗口，检查聊天显示；点击上方刷新，来回切换窗口，打开设置后再关闭。
4. 在「设置 → 版本与更新」检查版本和官网入口；无通话、录音或待处理附件时，可验证一键重启。

测试使用隔离数据和合成聊天页面，没有替用户发送真实消息。真实账号现场验收需在退出旧版并安装此包后完成。

- Google Voice 顶部和侧边两种导航、代理设置与 Signal 草稿保留的既有浏览器检查通过，没有发送真实短信或修改真实账号。
