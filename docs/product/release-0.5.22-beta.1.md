# HelloDog 0.5.22-beta.1

本机测试版：修复 WhatsApp、Telegram 和 Google Voice 的语音翻译入口缺失。在原语音气泡下显示英文与中文，保留原播放器；继续通过手动点击“转为中文”触发。Signal 沿用已经验收的双语语音功能。

- WhatsApp 补齐延迟加载、按钮属性变化与新消息编号的识别，语音入口初始化不再被侧栏等独立功能的异常阻断。文字发送保护初始化失败时仍保持阻断，刷新后才能恢复。
- Telegram 的语音入口不再等待远端设置；可见旧消息、内嵌音频文件和隐藏译文时仍保留手动入口。
- Google Voice 补齐自定义语音留言播放器、无原生音频标签的控件和不同语言的播放图标。每条消息独立记录，避免相同音频出现在不同留言时共用记录。
- 只有能确认属于当前语音的音频才直接读取。官网不提供可靠音频地址时，在原气泡内选择从这条语音下载的音频文件；结果仍在该气泡内显示。此版本不新增实时通话录音或通话翻译。
- 切换会话、替换或删除语音、回收旧气泡及取消文件选择后，丢弃失效结果；重试沿用原消息记录，避免重复预览重复扣费。

## 验证范围与发布边界

自动检查覆盖页面识别、真实浏览器中的合成语音解码与文件选择、双语布局、跨账号隔离、消息切换和结算重试。实际运行结果保存在 `verification/voice-all-apps-20261012`。合成页面通过不能替代 WhatsApp、Telegram 和 Google Voice 真实账号的按钮与语音验收。

用户明确要求“暂不上线”。本版仅供本机验收，不修改云端翻译服务、数据库、官网、正式安装包或自动更新清单。
