## 仍需在 Search Console 操作

本轮没有访问到已登录的 Search Console，因此没有替用户点击“请求编入索引”，也没有新收录或搜索排名的当前证据。
此前用户截图显示首页已收录，下载页尚未收录；截图属于当时状态。

1. 在网址检查中分别输入首页、下载页、/guide 和 /updates 的完整 HTTPS 地址。
2. 点击“测试实际网址”，确认允许抓取和编入索引后，对需要更新或新建的页面请求编入索引。
3. 继续使用原站点地图 https://hellodog.net/sitemap.xml 。它已经包含 4 页，无需删除旧提交。
4. 等待 Google 再次读取。站点地图读取成功、网址测试成功与正式收录是不同状态，不要反复提交同一页面来代替观察报告。

## 搜索效果的实际观察方法

每周在 Search Console 的“效果”报告中筛选查询包含 hellodog，分别查看 hellodog 与 hellodog 翻译器。

记录查询词、日期范围、展示次数、点击次数、平均排名、页面、国家和设备。
比较相同国家、设备和等长日期范围。数据不足时记为“暂无足够数据”，不要填成 0 或宣布失败。
先观察用户能否看到正确官网，再观察点击与下载入口使用情况。
没有默认开启新的自动监控、邮件或通知任务。

Google 决定收录、标题显示与排名。页面更新和官方项目介绍有助于建立一致信息，但不能承诺第几天进入首页或排在第一名。
