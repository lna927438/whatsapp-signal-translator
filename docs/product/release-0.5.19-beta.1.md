# HelloDog 0.5.19-beta.1 本机修复候选版

本版修复 Signal 语音翻译失败、气泡反复闪动，以及译文/错误提示重叠。

- 修正语音识别模型在 Windows 中文安装目录下的读取方式。保留原组件、文件校验与识别取消机制。
- 文字翻译只清理自己创建的文字节点，不再删除语音翻译面板。
- 为语音面板设置正常行高，避免继承 Signal 媒体气泡的零行高。

语音仍需手动点击“转为中文”。不自动播放、录音或发送，原语音保留。

验证覆盖两个实际页面观察器、Signal 自身 Electron 隔离预加载环境、合成音频解码/IPC，以及本机中文安装目录中的真实识别组件。合成语音在旧模型路径方式下失败，修复后成功；中文输入/输出路径也通过。

真实聊天中的这条语音仍需本机验收。未公开发布，未自动替换现有安装，也未修改服务器或计费。
