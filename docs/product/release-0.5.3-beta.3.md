# HelloDog 0.5.3-beta.3 本地测试版

本轮面向日常聊天，继续完善四轮体验与稳定性改进。不公开发布，不修改线上服务、套餐、支付或用户余额。

## 使用

优先运行同目录的 `Start isolated test.cmd`，使用独立测试数据目录。测试版需要单独登录 HelloDog、关联平台账号。不要把测试目录误认为原安装版的数据丢失。

需要安装时使用 `HelloDog Setup 0.5.3-beta.3.exe`。本地包未代码签名。原版、测试版请勿同时操作同一个账号数据目录。此包附有修改后的 Signal 对应源码与校验清单。

## 本次变化

1. 发送：包含上一批输入法候选词、229 键码、Shift+Enter、连续发送与超时修复。等待中的翻译不得覆盖下一条草稿；平台发送结果未知时继续查询原任务，不自动重复发送。
2. 翻译：移除把 cap、based、NPC、SB、TM 等词直接猜成俚语或辱骂的固定映射。有上下文、语气或术语要求时交给翻译服务。明确的少数英语缩写保留免费处理，简繁中文分开。
3. 恢复：唤醒后分别恢复各服务，单个等待不会拖住其他窗口。恢复请求合并，超时仍在后台运行的操作不重复启动。
4. 清理：Signal 删除、撤回和限时消息增加持久清理通知。先保存清理决定，再清除 HelloDog 中的译文、请求正文与相关上下文；重开后重试未完成清理。迟到结果不能恢复已清理的正文，已发生的扣费仍照实记录。
5. 保留期：在“记录与恢复 → 隐私与诊断”选择手动管理、7、30 或 90 天。按当前 HelloDog 登录用户生效，保存前显示影响条数。仅清理已完成的本机翻译记录、缓存和已完成发送的恢复副本；不动草稿、待确认请求和待处理发送。
6. 媒体：旧版 Signal 媒体视图切换账号或附件后丢弃旧响应。附件读取超时可重试；图片预览支持 Esc、焦点返回和 Tab 键约束。官方 Signal 媒体组件继续沿用原生实现。

保留期不清理平台聊天数据库，包括 Signal 中随已发送消息保存的原文注释，也不改变云端保留规则。已经删除或到期的 Signal 消息按照消息清理流程处理。缩短保留期后，延长保留期不会恢复已清理内容，也不会自动创建新翻译。

7. 帮助：快捷操作提供中英文说明，覆盖发送、换行、历史、未知结果和麦克风/摄像头检查。整套客户端的完整英语界面仍未完成。

## 验证与边界

自动回归 287 项通过，0 失败。HelloDog 界面、主进程、测试工程和固定版本 Signal 类型检查通过。官方 Signal 输入组件完成本机 20 条连续输入、回车和点击、emoji 图片附言、纯图片、换行、输入法事件和附件准备中阻止发送检查。

这些测试没有向真实联系人发消息，没有拨打真实电话，没有产生真实 API 翻译费用。硬件输入法、休眠、网络切换、真实双向媒体、15 分钟通话、8 小时后台和多显示器 DPI 仍待实机验收，不能据此宣布四轮全部通过。

已获准使用用户现有的 HelloDog 登录账户开展测试。WhatsApp/Signal 的具体测试接收账号与已同意参与的联系人尚未指定。

## 建议实测顺序

1. 单个平台发送一条中文、英文、emoji、图片附言，确认手机端与对方收到的内容。
2. 连发 20 条，期间继续写下一条草稿；切换联系人、输入法选词和 Shift+Enter。
3. 翻译时断网、恢复连接、刷新、重开；核对原请求，不直接补发未知状态的消息。
4. 设置短时限消息，删除和到期后重开应用，检查聊天和 HelloDog 记录均无译文复现。
5. 双向音视频与通话、托盘、锁屏、休眠、8 小时后台，再扩展多个账号。

正式发布仍暂停。测试结果记录在 `verification/experience-stability-beta3/`。
