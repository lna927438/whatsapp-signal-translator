# HelloDog 0.5.2-beta.7 本地修复记录

日期：2026-09-11。仅供本机测试，未发布上线。

## 本轮修复

- Signal 普通输入栏在有文字或附件时显示发送按钮，继续使用官方发送队列。
- 提交时读取当前文字，避免快速输入后按回车被尚未更新的界面状态拒绝；输入框提交失败会释放本地提交锁。表情补全尚未初始化时不会直接吞掉回车。
- 嵌入窗口清除不适用于子窗口的弹出窗口标志，保留输入和后台任务所需的定时器，并在窗口获得焦点时恢复网页焦点。
- 从手机同步的 Signal 已发送历史消息可显示译文。已有 HelloDog 发送原文直接恢复；未缓存且未开启历史自动翻译的消息提供单条“翻译”入口。
- Signal 和 WhatsApp 都会丢弃设置变化期间返回的旧显示结果。页面重用消息行、替换文字节点、重新打开聊天时恢复正确译文。
- WhatsApp 兼容不带方向前缀的消息编号，通过本条消息的原生回执图标识别已发送消息；支持 plaintext-only 输入框。
- WhatsApp 按账号和平台消息编号保存已发送原文，重开后恢复时不再进行付费回翻。不同消息文字相同仍是不同消息；编辑过的消息不会拿到旧原文。
- 顶部“历史”选项仅影响当前账号，可选新消息自动、可见消息自动或点击翻译。已有全局偏好继续有效。

## 使用

从 beta6 菜单选择“文件 → 退出”，再运行 release/beta7 下的测试入口。点击 X 默认进入托盘，因此需要明确退出旧版后再打开新版。

新版默认沿用 `HelloDog-test-beta6` 测试数据目录，保留已关联 Signal、WhatsApp 登录及草稿。beta6 安装文件与原正式客户端不被覆盖。打包检查另用全新的 `--test-profile=beta7-smoke`，不会占用实测账号。

历史自动翻译会对没有缓存的消息按现有规则发起翻译；读取已有原文和译文不新增翻译。结果未明的旧发送任务继续保留，不会为了消除待确认状态自动重发。
