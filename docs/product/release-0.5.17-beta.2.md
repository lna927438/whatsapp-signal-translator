# HelloDog 0.5.17-beta.2 本地验收与 OpenAI 接入

2026-09-22。客户端仅生成本地测试包，不上传安装包、不修改官网客户端版本、不自动覆盖现用软件。

## 设置与模型

- 设置页仅保留 OpenAI 和 DeepSeek，显示服务端实际完整模型 ID：`gpt-5.6-luna`、`deepseek-v4-pro`。模型名字与可用状态分别显示；配置名字不代表通道已经启用。
- 「新窗口默认翻译模型」只影响以后创建的 WhatsApp、Signal、Google Voice 窗口。已有窗口继续保留各自选择，可在窗口上方切换。
- 两通道共用语言、语气、术语、译文预览、回翻及用户字符余额规则。旧请求、待核对和重试沿用第一次的通道和请求编号，不因切换重复扣费。
- 连接页显示两个模型的状态。点击测试时固定本次模型、文本、语言和设置；等待登录期间改动会取消尚未发出的测试，已经发出的旧结果不会显示在新选择下。
- 点击「刷新模型状态」会立即重新查询，启用通道后无需等待旧缓存失效；多个窗口同时刷新仍合并为一个检查请求。
- 移除旧个人 DeepL / Google Cloud Translation 的设置入口、运行代码和密钥字段。新版启动迁移保留账号、聊天、草稿、代理、窗口排序、语言、历史回执，以及不属于旧翻译服务的其他设置。
- 本版继承 beta.1 的备注移除、侧栏拖动、在线状态、颜色确定/取消、首页与侧栏简化、最新版通知等修改。

## 后台和服务器

后台同步两通道完整模型名、开放状态、默认通道、各自调用数、Tokens、API 费用与合计。未取得价格的调用明确显示待核算，不记为零。用户端只看总字符余额和总用量。

正式服务继续默认使用 DeepSeek，不新增自动切换到 OpenAI 的备用路由。旧版不带通道参数的请求保持原行为；新客户端明确选择的通道不会被静默替换。

服务器与管理后台已更新并完成线上核验。定时任务、域名、日志设置和正式客户端下载清单均保持不变，官网客户端仍为 0.5.16。OpenAI 显示配置的完整模型名，但在新密钥获得服务器使用授权前保持未启用。

普通 OpenAI API 密钥用于翻译和按 Tokens 回执计算费用。OpenAI 官方账单自动读取是另一个权限，尚未接入，不能将回执计价称为官方账单。

## OpenAI 接入步骤

1. 现有新密钥已经通过本机测试。目前仍受此前「仅用于本机」的授权范围限制，尚未上传服务器。请在聊天确认是否允许将它保存到 HelloDog 服务器加密配置 `OPENAI_API_KEY`；不需要在聊天发送密钥。
2. 确认后，仅为已配置的 `gpt-5.6-luna` 开放 OpenAI 选择，DeepSeek 继续默认。清除经核对属于旧账号的故障退避状态时，保留历史请求和账本。
3. 本地验收新版时，先保存草稿并从「文件 → 退出」退出旧版，再安装本地测试包。客户端密钥不需要填写。
4. 打开「设置 → 翻译」，刷新模型状态。新建窗口可选择默认模型；已有窗口使用上方按钮切换。
5. 在设置里选择 OpenAI，点击一次「测试翻译」。成功的独立测试正常计字符，失败不扣用户字符。核对后台新增的 OpenAI 调用、Tokens 和费用分项。

参考：[OpenAI GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)、[DeepSeek 模型接口](https://api-docs.deepseek.com/api/list-models/)、[Cloudflare 加密密钥配置](https://developers.cloudflare.com/workers/configuration/secrets/)。
