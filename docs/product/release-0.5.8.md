# HelloDog 0.5.8

提升安全防护与运行稳定性，修复 Signal 翻译及图片查看、复制和保存问题。

本版包含 Signal 可见历史消息失败重试、跨进程消息参数修正、图片右键复制与保存、按月缩略图相册及连续预览。客户端启用运行隔离、敏感数据加密存储、更新签名和安装包内容校验。

2026-09-14 用户明确选择跳过付费证书和实名认证并继续正式上线。本版没有 Windows Authenticode 签名，安装时可能显示未知发布者。更新元数据使用独立 Ed25519 密钥签名；客户端验证密钥、版本、有效期、文件长度和 SHA256，拒绝篡改或降级。该选择仅改变安装包的 Windows 发布者验证方式，不关闭更新签名、权限校验或其他安全功能。

生产更新公钥内置于程序归档。加密私钥与 Windows 用户保护的口令保存在 D 盘仓库外的受限目录。当前公钥标识为 hellodog-update-20260914。密钥轮换须先分发新公钥；正式元数据有效期为 90 天，后续发布或续签需在到期前完成。

升级前退出 HelloDog，再安装官网新版本。保留现有用户资料、账号和本地草稿。0.5.7 客户端使用现有升级通道获取本版；安装本版后后续更新启用签名验证。首次安装依赖官网 HTTPS 来源，本版不声称已通过 Windows 发布者实名验证。
