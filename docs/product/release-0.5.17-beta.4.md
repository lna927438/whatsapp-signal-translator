# HelloDog 0.5.17-beta.4 本机 OpenAI 试用

本包仅用于本机验收，不公开发布；官网版本和自动更新文件保持不变。OpenAI 是否可选由服务器按已登录的 HelloDog 账号授权，供应商密钥保存在服务器，不进入客户端。

- WhatsApp、Signal、Google Voice 每个窗口保留独立模型选择。切换仅影响新翻译；已生成译文、待核对请求和发送草稿保留原通道，避免重复调用和重复扣费。
- 通道状态通过已登录账号验证。缓存按账号隔离，退出或切换账号时失效；旧账号的延迟响应不能进入新账号界面。
- 登录短暂恢复失败后可以立即重新读取通道状态。认证或服务故障时不会沿用旧的试用权限；旧服务器缺少新接口时只使用公开通道状态。
- 修复聊天顶部刷新通道状态未真正绕过缓存的问题，模型全名继续由服务器提供。

验收使用合成数据，不自动发送聊天消息。安装前应从“文件 → 退出”正常退出旧版，保留原安装目录和账号资料；安装及实际 OpenAI 账号权限需另行核对。
