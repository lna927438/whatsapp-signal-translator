# HelloDog 0.5.10

修复翻译失败后的重试与发送卡顿，新增独立红色备注，优化联系人状态显示。

## 原因与修复

只读生产聚合及去除正文和身份信息的运行日志确认，翻译提供方出现 HTTP 503。此前提供方超时为 45 秒，客户端在 30 秒结束请求；客户端离开后，未明确保留的云端结算可能中断，记录直到超时清理前都处于处理中。当前将提供方等待限制为 20 秒，保留请求结束后的结算执行，并对同一结算进行有限重试。失败解除预留，不修改实际余额；结果未知时继续核对原编号。

历史请求在本次查询中从待确认变成失败后，现在立即使用正确状态。发送重试只为已确认失败且未扣费的翻译创建持久化的后续编号，聊天发送任务编号保持不变；并发重试合并，重启后继续沿用。翻译阶段的待确认不再误标为平台已发送待确认。记录面板可恢复重启遗留的翻译任务；已发出但结果不明的聊天消息继续禁止自动重复发送。

手动恢复翻译成功后解除此前的暂停，让后续消息继续处理。中文原文拦截、零可用字符拦截和低于 50,000 字符红色提醒保留。

## 备注与状态

账号标签新增独立红色备注，原来的账号名称备注保持独立。WhatsApp 联系人名称下另有红色备注，按 HelloDog 登录用户、应用账号和稳定联系人标识分别加密保存在本机，可修改或清空，不作为聊天消息发送。未能确认联系人身份时不允许写入，防止备注串到同名联系人。

正在输入、正在录音、在线和最后上线仅展示 WhatsApp 当前提供的状态；原状态隐藏、移除、断网或切换联系人时清除旧显示。不推断受对方隐私设置隐藏的上线时间。备注位于标题区域正常布局中，不覆盖聊天内容。

## 验证与限制

417 项自动回归通过，覆盖失败后恢复、重启与并发、结算幂等、后续消息继续翻译、字符余额、联系人隔离及隐私状态变化。实际浏览器组件样例通过 1280、980、760 像素布局检查。产物和线上检查另记录于 verification/translation-recovery-2026-09-15。

提供方仍可能出现超时或故障，本版改善失败处理，不承诺翻译永不失败或语义百分之百正确。未向真实联系人发送测试消息。沿用独立更新签名与安装包校验，不新增付费 Windows 代码签名证书；不变更数据库结构。
