## 下一步执行顺序

1. 使用本轮安装包验收文字发送、回车、历史恢复、刷新与重启。记录时间、平台、版本、复现步骤和脱敏请求编号。
2. 补齐原生限时消息清理及可配置的数据保留期；限制清理只触及已完成且允许清理的内容，保留防重复处理所需的非内容标识。
3. 完成真实媒体/通话及后台多账号验收，再处理实际发现的兼容问题。
4. 持续记录真实用量并按供应商账单核对；管理员二次验证和安全恢复单独验收。
5. 完成签名、安装/更新恢复与官网内容核对后，再决定是否发布。套餐价格、支付和新增平台不在当前上线前范围。
