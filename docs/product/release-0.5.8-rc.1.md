# HelloDog 0.5.8 发布候选

状态：0.5.8-rc.1，本地验收包；用户已授权上线，尚未公开发布。

## 对外更新说明

提升安全防护与运行稳定性，修复 Signal 翻译及图片查看、复制和保存问题。

## 已实现

- Signal 手动翻译只传递消息标识，避免响应式界面对象造成跨进程复制错误。可见历史消息遇到失败后分次重试，恢复网络或刷新后可以继续补译，接口返回的译文直接显示。
- 图片支持右键复制、保存；使用当前 Electron 的异步剪贴板接口并等待写入完成。无扩展名的照片按媒体格式补充扩展名，保存保留原始文件字节。
- 媒体、链接和文件分别展示。照片、视频使用按月份排列的缩略图，支持连续查看、左右切换、复制、保存和 Esc 关闭。附件按需读取，大量媒体分批展示。
- 图片操作检查当前账号、对话、主窗口及消息有效期。切换账号或内容过期后，拒绝继续读取或导出。窄窗口使用适应宽度的媒体栏，常用桌面宽度下不覆盖聊天区。
- 合并此前的本地安全加固：进程隔离、受限接口、敏感记录加密、更新验证等。服务端管理员验证、费用保护及其他安全配置的具体启用状态另见验收记录。

## 发布条件

正式 Windows 签名证书及更新签名身份尚未配置。生产签名检查保持启用，不将未签名候选包推送给用户。

未使用真实联系人发送测试消息或拨打电话。相册显示此设备实际持有且未过期的媒体，不能补回未同步到设备或已经消失的照片。部分图片格式若系统不能解码，会明确提示保存后查看。
