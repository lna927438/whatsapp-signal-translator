# HelloDog 0.5.11

优化历史消息自动翻译、联系人备注与费用统计，提升稳定性与安全性。

## 翻译恢复

修复历史消息连续失败后永久耗尽自动重试次数的问题。改为持久化的五分钟恢复窗口，每个窗口最多两次自动恢复，滚动和重启不会重置窗口。旧版遗留记录在等待窗口结束后也能恢复，不要求清空聊天或删除翻译记录。

确认失败且未扣费的翻译才能创建后续请求；结果未知的请求先查询原编号，只有云端确认不存在时才沿用原编号重试。已完成的译文继续读取缓存，保持并发合并及单次字符扣费。中文原文发送拦截、零字符发送保护和低余额提示继续生效。

WhatsApp 登录或余额限制解除后会定期重新检查，避免页面的暂停状态永久阻断历史翻译。空响应保持可重试，不再标记为已完成。Signal 历史消息接入同一恢复流程，并修复原生聊天页面静止时不会在冷却结束后再次扫描的问题。历史记录短暂写入失败不再让后续读取持续收到旧错误；真正不可读取的存储仍停止操作，避免丢失计费状态。

## 联系人备注

联系人列表姓名下方与聊天顶部显示同一联系人的红色备注，可以独立编辑。备注按用户、应用账号和稳定联系人标识隔离；无法确认列表身份时先打开该聊天核对，禁止仅按显示名称关联备注。备注在本机加密保存，不作为消息发送给联系人。

## 用量与费用

后台突出已用字符与 API 花费。双通道按实际调用尝试分别核算，客户字符只扣一次；待核算金额与已知金额分开。官方余额、官方账单和本地回执核算保留各自来源与同步时间，不以充值余额变化推算支出，不将无回执的旧记录补为零。

官方账单同步受提供方权限、统计周期及数据延迟影响。OpenAI 需要独立管理密钥及 HelloDog 项目与密钥范围；更换前的账号费用需单独核对。DeepSeek 余额每五分钟自动同步，账期费用通过官方导出账单核对。后台本地流水每十秒刷新。API 费用按实际调用时间统计，字符按业务请求时间统计，并明确显示账期时区。

## 验证

回归覆盖连续失败、等待窗口、重启、并发、原请求核对、静止页面恢复、联系人隔离与列表复用。构建与线上验收证据记录于 verification/maintenance-2026-09-15。发布继续使用受信任的更新签名和安装包完整性校验。
