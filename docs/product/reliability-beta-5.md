# HelloDog 0.5.2-beta.5 本地测试说明

本轮修改翻译发送队列、WhatsApp 聊天列表分隔线和 HelloDog 图标栏。未上线、未执行安装程序、未打开或修改已安装客户端的用户数据，未向真实联系人发送消息。

## 发送延迟与连续发送

- WhatsApp 输入框在原文保存成功后即可继续输入。多条消息并行准备翻译，向平台提交时保持顺序。Signal 的发送队列也提前并行准备后续译文。
- 前台发送优先于历史消息翻译，历史加载不再占满全部翻译处理位置。短时间连续翻译会共享一次服务能力查询，每条消息仍使用独立的计费请求。
- 新草稿与待发消息分开保存；上一条消息提交时会恢复正在编写的下一条草稿。下一条草稿恰好与上一条译文相同时也不会被清空。
- 同一次操作的保存重试、翻译重试和已完成结果重放保留原任务身份。用户重新输入的另一条消息有独立身份，即使文字相同也不合并。
- 本地保存无响应、翻译失败或超时后释放输入；原任务保留，可以重试原任务。发送结果未知时只继续查回执，不自动重复点击发送，也不阻塞后续新消息。
- 切换联系人后不向新联系人提交旧译文。回到原对话可继续原任务；断线或重开后恢复记录不会自行重新发送。
- 平常发送没有审核步骤或核对浮层。等待中的消息在聊天区域以待发气泡显示；失败时保留原文和重试入口。只有用户自行打开“发送前展开译文预览”时才显示预览，暂不发送会保留原文和译文。

这些修改减少界面等待和前台排队，并不保证外部翻译服务或网络延迟消失。本轮没有用真实付费请求测量云端翻译耗时。

## WhatsApp 列表宽度

聊天列表右边缘可左右拖动，宽度按 WhatsApp 账号保存。双击分隔线恢复默认宽度；聚焦分隔线后可用左右方向键微调。调整范围会随窗口宽度变化，为右侧聊天内容留出空间。

已验证结构模拟页面中的真实鼠标拖动、键盘调整、宽度保存和窄窗口布局。仍需要在登录后的当前 WhatsApp 页面上确认匹配，因为官方网页结构可能变化。

## 图标栏

账号图标单独占一栏，不附带账号名称文字；悬停查看名称和状态，保留未读标记和右键菜单。账号多时独立滚动，底部操作始终可见。

账号栏宽 52 像素；旁边的功能栏可收起，两栏展开合计 96 像素。Ctrl+B 显示或隐藏功能栏，Ctrl+K 或 Ctrl+Shift+F 搜索账号。搜索支持名称、平台和分组。从搜索结果返回 WhatsApp 时会恢复聊天页显示。

## Signal 官方全功能的进度

**尚未实现完整官方功能。此版本继续使用 signal-cli 0.14.7，不包含新接入的贴纸、GIF 浏览、媒体发送或语音／视频通话。** 原有的基本设置、资料、联系人、存档、文件夹和接收附件能力保留；这些不等于官方客户端全功能。

已取回并锁定官方 [Signal Desktop v8.27.0](https://github.com/signalapp/Signal-Desktop/tree/v8.27.0) 源码，提交 `1a1d65153be546836d5948cb50493d4d1d293d02`。已核对输入编辑器、表情、贴纸、媒体编辑、设置、发送队列和通话服务的入口，保留上游许可证。源码准备记录位于 `integrations/signal-desktop.lock.json`，本地检查结果在 `verification/beta5-signal-core-preflight.json`。

完整接入技术上可行，但需要保留官方客户端的消息、存储、媒体和 RingRTC 通话体系，再接入 HelloDog 翻译与多账号窗口。单独复制界面按钮不能提供相应通信功能。

当前尚未编译或集成官方内核。官方固定的 Node.js 版本为 24.17.0；本机当前版本为 24.19.0，标准安装清单和 PATH 中未找到所需的 Visual Studio C++ 工具，官方依赖也尚未安装。其 Windows 构建要求可查阅[官方开发说明](https://github.com/signalapp/Signal-Desktop/blob/v8.27.0/CONTRIBUTING.md#windows)。这些是当前准备工作的状态，不表示完整集成只剩安装编译工具。

后续内核接入还需要独立数据目录、窗口和焦点联动、翻译与官方发送队列的衔接、媒体及设备权限、手机关联、真实双向消息和通话验收。现有 signal-cli 数据库不会直接作为官方客户端数据库打开或覆盖。

## 本轮实机验收重点

1. 连续发送三到五条短消息，第一条翻译期间继续输入，确认顺序、原文和新草稿均正确。
2. 翻译期间切换联系人；回到原联系人后继续原任务，确认没有串发。
3. 断网后恢复，观察原任务能否查回结果；已提交但结果未知的消息不要作为新消息重新发送。
4. 连续两次主动发送相同文字，确认是两条消息；同一失败任务的重试则继续原请求。结合翻译记录、余额与云端账本核对实际扣费。
5. 拖动 WhatsApp 聊天列表分隔线，缩小窗口、重开账号，检查宽度和输入框；打开账号搜索再切回 WhatsApp，检查是否出现空白。

上述真实账号、云端扣费、实际网络切换、锁屏和休眠测试本轮没有代替用户执行。更多平台、语音翻译和营销功能仍未加入本轮。
