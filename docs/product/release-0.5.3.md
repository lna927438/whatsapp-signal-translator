# HelloDog 0.5.3

2026-09-12。用户授权将已验证的 0.5.3-rc.2 修复发布至正式下载渠道。本次仅调整发布版本和对应源码说明，不更改已验证的聊天逻辑；套餐、定价和支付仍未开放。

## 更新内容

- WhatsApp 连续发送通过原生编辑器同步交接文本，修复吞回车、草稿拼接和发送回执残留。下一条消息可在上一条草稿保存期间进入队列。
- WhatsApp 在缓存和付费入口按账号、原生消息编号及正文恢复原文，避免已发送的译文因页面重绘再次扣费。不同消息即使文字相同仍分别处理。
- Signal 待发送或发送失败的原文不再被接收翻译重复处理；已发送的历史消息和保存的原文注释保持正常显示。
- 包含中英文界面、齿轮设置、一键重启、紧凑账号栏、WhatsApp 会话列表调宽、账号隔离、历史与草稿恢复，以及基于 Signal Desktop 8.27.0 的媒体功能。

## 已完成的验证

修复版通过 304 项自动化测试。WhatsApp 与 Signal 各完成真实自发 20 条，分别为 20 笔扣费，未出现额外付费请求。Signal 的图片、表情附言、文件、音频、视频及 GIF 完成自发检查，音频和视频解码播放正常。刷新和升级检查保留账号、登录、草稿和原文；历史恢复未新增扣费。

这类自发测试不能代表另一账号收到消息或通话成功。自动化操作总耗时不能作为纯输入延迟承诺。先前测试暴露的 22 笔多余扣费共 705 字符，已通过管理员逐笔补偿并保留账本。

## 已知验证范围

另一账号的双向媒体、15 分钟音视频通话、设备切换、物理输入法、真实网络切换、锁屏/休眠和 8 小时多账号运行尚未全部实测。Signal 富文本及编辑消息暂不自动翻译。Windows 安装包未进行代码签名。本次发布不代表这些项目已经验收通过。

## 安装、源码和回退

正式更新沿用原账号数据目录。安装前退出客户端；独立测试数据不会自动合并。下载文件与对应源码 SHA-256 见本版本 release-manifest.json 及官网下载页。

云端保留前一正式版 0.5.2 的安装包和对应源码。0.5.3 使用受保护的本地记录格式，不能直接使用 0.5.2 读取；客户端会阻止不兼容的降级。发生问题应保留当前数据并使用兼容版本修复，或在有匹配旧数据备份时恢复。官网和 API 的部署回退记录独立保留。
