# 官方账单与余额同步

本次只更新云端和管理后台，客户端继续使用 0.5.11，既有安装包与对应源码归档保持不变。

OpenAI 管理密钥通过本机密码输入窗口接收，只保存到受限的 D 盘文件和云端秘密配置。已用官方项目与密钥列表匹配当前 HelloDog 翻译凭据，费用请求明确限定项目、密钥和 UTC 账期。每五分钟读取本月官方 Costs，后台可指定账期查询；分页、金额原始精度与完整日桶均需通过校验后才能保存。近期官方金额可能继续补记。

DeepSeek 官方余额由后台可见页面每三十秒查询、云端每五分钟补同步；各页面和云端任务共享数据库刷新租约，避免并发重复查询。只允许服务端访问刷新状态和快照。余额保留官方原始十进制字符串、币种、充值部分和赠金部分，并精确检查组成部分相加等于总额。官方未提供余额出账时间，因此显示的是本系统成功采集时间。

手动刷新和自动刷新更新同一余额卡。查询失败不会把余额变成零，也不会更新成功采集时间；页面会标记未更新或过期。凭据改变后清空当前展示，旧请求结果不能覆盖新租约。两个币种分别显示，不自行换汇。

官方账户余额与所选账期消费分开。DeepSeek 公开接口尚无账期消费 API，官方账单可通过现有人工录入进行核对；这不是自动导入 CSV。历史缺失回执、无法归属的官方差额仍为待核算，不使用余额差额或当前价格改写旧记录。

OpenAI 官方费用包含该密钥所有调用，包括未进入客户业务流水的诊断调用。当地业务费用和官方费用分别展示；官方回执不按用户字符数推算。现有客户扣费与翻译函数不因本次改动而修改。

部署顺序为新 DeepSeek 状态迁移、带三项 OpenAI 官方账单秘密配置的 API 版本、后台网站，再验证真实快照与定时任务。独立账务核算、运行环境验证及发布记录保存在 `verification/billing-live-20260915`。密钥值不会出现在日志、网页或发布源码中。
