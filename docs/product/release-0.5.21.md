# HelloDog 0.5.21

语音消息点击“转为中文”后，在原语音气泡下显示英文与中文，保留原语音；新增 Telegram 官方 Web A 工作窗口，并减少历史翻译的重复读盘、解密和隐藏窗口扫描。

- 英文语音保留英文识别原文，生成中文；中文语音保留中文识别原文，生成英文；其他语言按需要生成两种译文。沿用原消息结算编号，分别复用已经完成的译文，避免重试或重绘重复扣费。
- 语音结果缓存返回前同时核验中文和英文原回执；任一目标已被清理时停止返回旧内容，不重新识别或创建付费请求。
- WhatsApp、Signal 和支持的 Google Voice 音频入口同步双语显示，切换会话后忽略旧界面的迟到结果，减少气泡闪动与重叠。
- Telegram 支持独立账号分区、逐窗口代理、常规文字和图片说明翻译、模型切换、未读状态与多窗口。语音没有可可靠对应到原消息的音频地址时，需要选择从该条语音下载的文件，译文仍显示在该语音气泡下方。
- Telegram 发送前核对会话、草稿、附件和目标语言。结果不明时不自动重发，同会话须先人工核对已有任务；旧历史加载不作为新发送回执。编辑、定时及付费等特殊发送流程仍会被翻译保护阻断。
- 历史查询使用带文件变更校验的只读快照；不同账号、不同消息保持独立身份。合成数据中，3,001 条记录的 80 次查询从约 454 毫秒降至 42 毫秒，此结果不代表网络或模型延迟。

## 验证与授权

候选版通过 1,624 项全量回归，后续 Telegram 专项 42 项和跨模块权限、计费 8 项检查通过；客户端与原生 Signal 类型检查、构建、语音资源、成品包和敏感信息扫描通过。语音气泡、窗口布局与人工核对面板通过隔离浏览器检查。

用户于 2026-10-12 在本机确认 Telegram 可以登录并显示已有会话，语音中英文正常且气泡稳定，随后明确授权“全面实装上线”。真实收发、接收端结果和异常网络恢复没有在本轮完成实机验收，不将自动检查描述为全平台真实收发验收。
