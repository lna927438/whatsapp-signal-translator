# HelloDog 0.5.18

本次更新增加手动语音转中文，并改善 Google Voice 内嵌窗口和客户端运行稳定性。

- WhatsApp、Signal 语音消息旁增加“转为中文”。点击后处理，保留原语音，在消息旁显示中文；识别原文可展开核对。
- 设置新增“语音翻译”，可选择聊天窗口和保存的语音文件。Google Voice 支持可确认来源的可见音频播放器；无法直接读取的播放器可使用文件入口。
- 语音识别在本机完成；识别出的文字沿用当前窗口的 OpenAI 或 DeepSeek 翻译通道，目标为简体中文。文字翻译按现有字符规则计费。
- 增加语音任务排队、超时、失败重试和重复扣费核对；切换账号、页面或音源，以及消息删除或过期后，旧结果不会写入新消息。
- 修复 Google Voice 登录页面可打开但连接检测误报的情况，改进代理连接状态、内嵌窗口刷新和消息翻译衔接。
- 修复打开内嵌窗口时可能出现的主进程日志管道错误，增加安装包登录配置和独立运行文件检查。
- 正式退出时立即停止语音识别，等待临时音频清理完成；关闭窗口到托盘继续保持原有行为。

语音文件最多 20 MB、5 分钟，格式以本机可以解码为准。语音识别可能有误，建议核对展开的原文。不包含实时通话翻译；第三方官网的特殊播放器可能需要保存文件后处理。

保留现有账号、代理、草稿和文字翻译流程。Windows 安装器沿用当前发行方式，更新清单签名及安装包完整性校验继续保留。对应源码随发行文件提供。
