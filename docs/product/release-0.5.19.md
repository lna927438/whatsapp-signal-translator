# HelloDog 0.5.19

修复 Signal 语音转中文失败、气泡反复闪动及译文重叠的问题。

- 修正 Windows 中文安装目录下语音识别模型的读取方式。
- 文字翻译刷新只处理自己的区域，避免反复删除、重建语音翻译面板。
- 恢复语音面板正常行高，使按钮、长译文和错误提示清晰显示。

语音仍需手动点击“转为中文”，保留原语音，不自动播放、录音或发送。

0.5.19-beta.1 已完成 103 项相关回归、原生 Signal 预加载和宽窄布局检查，以及本机中文路径中的真实识别组件验证。用户在原 Signal 会话验收后确认“翻译正常，气泡稳定”，并明确批准发布。本正式版保持相同功能代码和 Signal 组件，仅更新正式版本及发布说明。

客户端修复发布不涉及翻译服务器、账户、余额或后台计费变更。
