# HelloDog 0.5.4

日期：2026-09-13。用户已授权正式发布。客户端从已完成验证的 0.5.4-beta.2 升为正式版，运行代码与该测试版逐文件比对；完整结果保存在 `verification/publish-0.5.4/`。

## 本次发布内容

- 压缩应用顶部：账号标签、连接与翻译控制合并，收起面板时应用内顶部约 62 像素，不含系统标题栏和菜单栏。
- 应用图标与账号数量、可编辑备注、未读角标、X 移除按钮；支持顶部或侧边布局，取消移除时保留当前聊天。
- 自动检查官网正式版本，提供官网下载入口和明天提醒；不强制关闭正在进行的聊天，不把相同或更旧版本当成升级。
- 改善我方消息、本地语言显示、手机同步消息、Signal 富文本/提及/编辑消息翻译；已有原文和完成记录继续复用。
- 改善 Signal 刷新、输入状态、真实未读与 Windows 通知接入；减少历史消息读取时的重复缓存写入。
- 保留原翻译请求及扣费记录，兼容两类 API 实际 usage 字段，不用字符比例推算真实 Tokens 和费用。
- 后台用户备注支持编辑、搜索、清空、修订冲突保护，仅管理员可见，已在现有后台上线。

## 验证及边界

325 项自动回归、隔离聊天界面、本地数据库后台页面、云端回滚验收，以及测试版安装包启动和设置保存检查通过。正式版另做运行代码逐文件比对、独立启动、官网资源和完整下载校验。

本轮没有真实消息收发或付费翻译。真实双向聊天、对方输入、系统通知、通话、长时间断网与休眠恢复仍需持续实机验收，不将模拟测试当作真实网络验收。Signal 核心沿用已构建的 8.27.0，未另外升级官方版本。安装包未做代码签名。

## 旧版通知能力

0.5.4-beta.2 和 0.5.4 具有自动更新提醒。登录后会检查，后台周期与缓存控制避免频繁打扰；已缓存的版本信息最长约 6 小时刷新，用户选择明天提醒后按其偏好延后。

0.5.2、0.5.3 及 0.5.4-beta.1 没有远程更新通知接收功能。发布版本信息或管理公告不能让这些已安装程序凭空出现弹窗，也不能证明通知送达。可通过官网或旧版手动检查更新升级。当前没有可靠的客户端版本在线名单和阅读回执，不能宣称全部在线用户已收到。

官网：[HelloDog 下载](https://hellodog.net/download)。对应源码随本版同步提供。
