# HelloDog 0.5.4-beta.2

日期：2026-09-13。客户端作为本机测试版交付，官网正式安装包与更新指针保持 0.5.3。管理员备注更新到现有后台，部署证据另见本轮验证记录。

## 本轮改进

| 项目 | 当前行为 |
| --- | --- |
| 顶部压缩 | 账号标签和连接、帮助、翻译面板按钮合为一行。收起翻译面板且无更新提醒时，工具栏与状态栏共约 62 像素，不含 Windows 标题栏和菜单栏。 |
| 应用账号标签 | 使用 WhatsApp／Signal 图标，数量入口也显示对应应用图标。标签显示备注或账号名称，保留独立未读角标。仍支持顶部或侧边布局。 |
| 账号备注 | 双击标签、按 F2、右键或账号设置均可编辑，最多 80 字符；清空后显示原账号名称。搜索同时匹配备注。 |
| X 移除 | 标签 X 打开现有移除确认；取消时保留当前聊天和草稿。确认后的移除执行原有任务保护和数据处理规则。 |
| 更新提醒 | 自动核对官网正式版本，在较新版本可用时显示轻量提醒和官网下载入口。支持明天提醒，重开后保留。检查失败不会打断聊天；不会把旧版本提示为升级。 |
| 历史与缓存 | 已完成历史翻译继续复用原请求和原扣费记录。减少每次历史读取时重复写入缓存文件；清理缓存后仍可从完成记录恢复。语气或术语改变不自动重算已完成历史，主动重新翻译建立新请求。 |
| 真实 API 用量 | 兼容 Responses 和 Chat Completions 两类实际 usage 字段，分别读取输入、缓存输入和输出 Tokens。缺失或矛盾数据仍按缺失处理，不用字符比例估算 Tokens 或实际费用。价格配置未改变。 |
| 后台用户备注 | 用户列表和详情显示管理员备注，支持编辑、清空和搜索；最多 1000 字符。记录操作者及修订，重复提交不重复保存，冲突时不覆盖新内容。备注仅后台可见，不修改用户名、字符余额或客户端资料。 |

## 验证

- 325 项自动回归通过，覆盖历史缓存与重复扣费、翻译请求、真实 usage、更新版本比较及提醒、账号备注、管理员备注权限与保存冲突。
- 客户端类型检查、后台生产构建和服务端构建通过。
- 真实 Vue 界面加隔离示例数据验证账号图标、备注、X 取消与确认、官网入口和更新提醒；850、1024、1260、1600 像素宽度无横向溢出，聊天区域边界正确。
- 本地 Postgres 兼容数据库加真实后台页面验证备注保存、搜索、刷新后保留、清空；云端使用事务回滚验证同样的数据库行为，未改变真实用户资料或余额。
- 打包后的启动、语言切换、重开保留和 Signal 核心文件检查结果见 `verification/feedback-0.5.4-beta.2/packaged-ui.json`。

## 实测边界

本轮没有向真实联系人发送消息，也没有消耗真实付费翻译。真实双向收发、对方输入状态、Windows 系统通知、通话和长时间断网恢复，需要在测试版中继续复测；不能由模拟页面或自动回归替代。

本版保留上一测试版的 Signal 8.27.0 核心，没有额外升级 Signal 官方版本。安装包未做代码签名。

对应源码：`HelloDog-0.5.4-beta.2-corresponding-source.zip`。校验值和安装包信息见同版本发布清单。
