# HelloDog 0.5.3-rc.1

2026-09-12。本地发布候选版。用户已授权完成四轮优化后上线；本包用于完成发布前验证，尚未替换正式下载。

## 本轮变化

- 登录页和设置增加简体中文、English、跟随系统。语言可即时切换，账号名称、联系人、原消息和未发送草稿保持原样。
- HelloDog 工作台、设置、记录与恢复、更新、帮助和常见错误增加英语显示。托盘、系统菜单和备份/清理确认跟随界面语言。WhatsApp 与 Signal 自带界面的语言仍由各平台设置控制。
- Signal 提交发送后断开连接，依据任务提交阶段保留“结果未知”，不依赖中文错误文案，也不自动重复发送。下一条草稿仍可输入。
- WhatsApp 的手动历史翻译和可选译文预览支持英语。切换界面语言仍读取原缓存，不因显示调整产生新翻译。
- 保留上一测试版的输入法保护、连续发送队列、历史恢复、保留期、媒体操作、齿轮设置图标、一键重启和可缩放 WhatsApp 会话列表。

## 验证边界

本地回归、构建、窗口布局、真实原生组件与隔离资料目录测试分别记录。自动化样例不是实际联系人送达证据。真实双向媒体、15 分钟通话、物理输入法、锁屏/休眠和 8 小时后台尚未完成本版本验收，不能据此声称“Signal 全功能全部实测通过”。

本版未开发套餐、价格或支付系统。安装包未进行代码签名。已安装旧版与新版本不能同时使用同一聊天资料目录；测试应先正常退出旧版，保存原有草稿后再接管。
