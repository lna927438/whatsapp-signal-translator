# HelloDog 0.5.16

本次修复翻译目标语言偏移、疑问句被回答和Signal原消息恢复问题。云端修复及对比证据见[翻译目标及疑问句](translation-target-question-2026-09-21.md)。

Signal内嵌核心重新构建：手动重试清理过期失败显示，合并重复入队并保留原消息ID和成功收件人状态；发送前翻译或权限检查有独立提示。历史免费修正可恢复到尚未成功发送的原消息；原消息与每个编辑版本严格对应账单记录。保存译文期间用户编辑、删除、过期或送达状态变化会停止继续发送，不覆盖并发新内容。

已完成的收费记录保持不变，恢复沿用请求ID。云端无数据库迁移，不更换通道、密钥或账户。真实发送未由自动化触发，不将单次API成功等同消息已送达。网络或平台拒绝仍显示原错误，需要用户在原消息上查看详情。

发布证据由verification/release-0.5.16记录。0.5.15的未验证Google Voice带说明图片、系统通知和官方账号限制仍如实保留；本次不扩大视频/音频/通话能力，也不声称消除所有模型误译。
