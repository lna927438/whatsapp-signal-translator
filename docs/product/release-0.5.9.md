# HelloDog 0.5.9

加强中文原文发送拦截，改善翻译恢复与发送稳定性，增加低字符余额提醒。

发送保护覆盖普通 Enter、组合键、发送按钮、启动加载期间及 Signal 原生重试。外语消息仍含中文时停止发送；翻译响应为空、权限未确认或余额无法核实时保留原消息。强制保护不受旧版关闭设置影响。用户主动选择中文或日文为目标语言时仍允许相应文字。

新翻译发送在准备与最终提交时检查云端字符余额。零可用字符时，缓存和免费短句也不能用于新的翻译发送。刚好使用完最后字符的同一条已付费请求，必须查到匹配的云端结算回执才能完成发送，不再扣费。纯表情和本来已是目标语言的文字不新增翻译费用。低于 50,000 字符（包括零）显示红色提示。

桌面端隐藏时继续维护登录，过期令牌刷新后仅重试一次原请求。短暂认证服务故障返回服务不可用，不冒充会话过期。历史或发送任务只有经认证查询确认云端未收到时，才能沿用原编号恢复；自动恢复次数持久化限制为两次。已处理或结果未知的请求不会新建编号重发。

WhatsApp 失败后可恢复中文草稿，未修改的恢复草稿沿用原任务重试，发送成功后不重复留下同一草稿。媒体说明或编辑弹窗中的中文暂采用阻止发送并提示先在聊天输入框翻译的保护方式，尚未提供所有官方编辑窗口的自动翻译适配。
