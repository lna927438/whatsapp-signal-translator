# HelloDog 0.5.12

改善翻译失败恢复，修复联系人备注；新增本地语音识别与语音文件翻译，优化字符扣费和余额同步，提升安全与稳定性。

## 翻译与计费

按用户要求，正式翻译仅使用 DeepSeek。明确收到完整但语言错误的答复时，最多追加一次纠正，仍禁止含中文的非中文发送；超时或结果未知不盲目重发。所有供应商尝试均计入成本预留和回执，最终成功只扣一次客户字符，失败释放预留。

官网账户页读取原子余额/用量快照并定期刷新；后台当前费用按启用通道汇总。OpenAI 的历史金额保留用于对账，账号标识与凭据移除。客户端启动清理旧的 OpenAI 密钥/模型配置，保留 HelloDog 登录与聊天账号。

## 备注

联系人列表和聊天顶部备注保持独立账号、稳定联系人身份及版本冲突保护。修复嵌套标题点击、导航中页面重绘、读取失败/超时后无法恢复的问题，不按同名联系人猜测身份。

## 语音

本地 CPU 语音识别无需 OpenAI 账号，用户核对并可修正识别文字，再确认翻译。识别本身不调用供应商；文字翻译按既有规则计字符。单条支持不超过 5 分钟，运行中可以保留原聊天操作。

能确认音频属于当前消息时，WhatsApp 和 Signal 兼容模式提供语音按钮。无法可靠读取内嵌音频或使用原生 Signal Desktop 时，先保存语音，然后使用“记录与恢复 → 快捷操作 → 语音文件翻译”。不会根据播放时间猜测音频属于哪个联系人。

识别模型和运行文件按固定哈希校验，每次执行验证，输入限制为规范 PCM；识别超时、登录切换或失败会终止处理并清理临时音频。音频不发送到翻译 API。口音、噪声与语言检测可能影响识别结果，因此保留翻译前校正步骤。
