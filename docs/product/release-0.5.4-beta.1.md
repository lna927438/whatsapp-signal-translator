# HelloDog 0.5.4-beta.1

日期：2026-09-12。交付范围：本机测试版；本轮未修改生产更新指针、官网或云端服务。

## 本轮改进

| 用户反馈 | 本版处理 |
| --- | --- |
| 我方发送的消息没有译文 | 区分“实际发送的译文”和“聊天中显示的本地语言”。直接发送外语、手机同步的已发送消息也能按设置补充本地译文；已有原文的发送任务复用原文，不为显示原文再收费。兼容聊天页面可以逐条翻译已发送消息。 |
| Signal 带格式、提及或编辑后的消息漏翻译 | 官方核心接入不再直接跳过这些消息。保留提及的用户和对应位置，编辑消息按原消息与编辑版本追踪，失败不覆盖原消息。 |
| Signal 对方输入中 | 兼容聊天页面接入真实输入事件，按账号、会话和发送者隔离；收到停止事件或过期后消失。官方 Signal 和 WhatsApp 继续使用各自原生状态。 |
| Signal 右键刷新无反应 | 平台图标右键关联到当前或最近账号；刷新实际执行连接检查和同步，合并连续点击，显示简短完成或失败结果。保留聊天草稿，发送或通话中使用安全重连。 |
| 左侧重复的软件图标占位置 | 固定一个 WhatsApp 图标和一个 Signal 图标，另外用编号切换各平台账号；显示当前平台账号数量。设置 → 外观 → 账号切换栏位置，可选顶部或侧边，立即生效并支持撤销。 |
| 官网入口 | 侧栏增加地球图标，打开 https://hellodog.net/download。 |
| 未读角标和通知 | 按平台和账号汇总真实未读数量，增加 Windows 任务栏与托盘角标；修复角标被裁切。官方 Signal 的提醒由 HelloDog 统一显示，避免重复提醒；不传递聊天正文给通知。 |
| 翻译恢复和流畅性 | WhatsApp 临时网络失败不再永久暂停自动翻译。兼容 Signal 只调度当前可见消息的显示翻译，限制并行数；消息提醒不再等待翻译结束。继续沿用原请求标识和未知结果核对机制。 |

## 使用与验收边界

安装包用于本轮反馈复测。已绑定账号、数据目录和生产余额不因导航改版而迁移或重置。

翻译后如不能准确对应局部加粗、斜体等格式，会简化这些局部样式；提及对象必须完整保留，否则该次翻译不会继续发送。整段样式和可以明确定位的格式保留。

本轮没有向真实联系人发送消息，没有验证另一台设备的真实输入状态、已读回执或 Windows 实际弹窗。应在反馈用户的环境中验证以下行为：

1. 中文翻译后发送、直接发送英文、手机发送同步、带表情/提及/编辑消息，实际收件内容正确，聊天下方译文完整。
2. 快速连续发送三条，切换联系人、加载历史和重开后没有重复发送或重复扣费；网络暂时失败后可恢复。
3. 对方开始、停止输入以及切换会话时，输入状态对应正确。
4. Signal 平台图标与账号编号右键刷新均有结果，草稿保留；有发送任务时不重发不明状态的任务。
5. 后台收消息后平台、账号、任务栏和托盘角标变化正确；打开聊天并实际阅读后清除，通知点击能打开正确账号。
6. 顶部/侧边切换并重开，位置保留；较窄窗口下账号列表可滚动，聊天区域不被覆盖。

Windows 通知身份与任务栏覆盖图标按 [Electron 通知文档](https://www.electronjs.org/docs/latest/tutorial/notifications) 和 [BrowserWindow 文档](https://www.electronjs.org/docs/latest/api/browser-window/#winsetoverlayiconoverlay-description-windows) 接入。实际系统提醒还取决于设备的通知设置和免打扰状态。
