# HelloDog 0.5.20

保留主动输入的段落，减少翻译额外产生的空行和空格；加强发送前核对，避免等待期间修改草稿后误用旧译文。

- 非中文、非日文目标的发送译文仍含中文时停止放行，保留原结算记录和草稿供修正。
- 断网或结果不明时继续查询原请求，不自动创建新翻译任务或重发聊天消息。登录恢复、通道检查与网络请求共用等待上限。
- 优化按消息编号读取翻译回执，释放已关闭页面的语音监听与定时器；切换账户后拒绝旧账户迟到的显示结果。
- 后台分别处理各通道账单读取故障；未取得的数据不显示为零。金额保留原始精度，显示两位小数，合计按原始金额计算。
- DeepSeek 自动累计充值消耗与手工月账单分开显示；OpenAI 官方账单按官方数据采集并标注时间和延迟。
- 保留语音手动转中文、经典 Signal 与内嵌 Signal 的原有组件和账户兼容路径。

本版沿用 0.5.20-beta.1 的功能代码；候选版已通过 1,569 项回归、类型检查、客户端/服务端/后台构建，以及隔离浏览器用例。用户于 2026-10-04 明确指示“上线”，授权发布客户端、云端和后台。本轮没有向真实联系人发送验收消息，Google Voice 等真实账户端到端收发仍未重新实测，不将自动检查描述为完整实机验收。

没有新数据库迁移或余额调整。恢复的三份历史迁移已在线执行，不得重复应用；线上编号对照见 `release-0.5.20-beta.1.md`。发布前保存当前 0.5.19 下载清单及云端回退版本，先部署兼容旧客户端的云端修复，再发布客户端清单。
