# HelloDog 0.5.15

Google Voice 官方页面在客户端内运行，每个账号窗口使用独立会话和代理配置。支持带认证的 SOCKS5 及四段式代理解析、检测、保存重连与出口 IP 查询。短信原文和译文放在同一气泡内；文字和本地图片发送前核对草稿及收件人，翻译期间修改草稿会使旧预览失效。

修复官方侧边导航收起时 HelloDog 未读数字被清空的问题。读取可见官方短信导航，导航不可见时仅接受实际观察到的严格短信标题格式；未知状态不猜数。用户于 2026-09-20 在 beta.10 实机确认外层已显示未读数字。桌面提醒需窗口设置与全局通知均开启，初次读取已有未读不触发新消息提醒。重启后先打开需要监测的窗口，随后切换应用仍继续监测。

后台汇总的退款关联原先对每笔翻译重复扫描该用户的流水。新增只包含退款的关联索引，不修改账本、钱包、计费函数、权限或退款匹配语义。生产同一月查询从 5937.708 ms 降到 241.467 ms；前后 7831 条账本、钱包总额、698091 已扣字符、1203 补偿字符及全部用量汇总保持一致，对账异常为 0。性能测量是当前规模的观测，不代表未来恒定延迟。

管理界面区分尚未取得与真实零值；刷新失败时保留成功数据并标注过期和时间。总览与费用独立加载，身份核验后的慢指标不再阻挡整个页面。分页、查询和会话切换不会接受过时响应。

验证：退款索引的完整汇总等值、精确文本关联、多笔退款求和、用户隔离与索引选用；真实前端组件错误恢复；Google Voice 收起与展开导航、真实 Electron 通信链和翻译预加载回归。最终构建、源码对应、完整安装包和签名更新证据由本次发布目录记录，不以旧版报告代替。

用户此前已验证 SOCKS5 真实线路和纯图片客户端送达，纯图片不扣翻译字符。文字在翻译成功后计费，同一草稿复用回执，确认发送不再重复扣该笔翻译；接收翻译为独立任务。当前提供文字与本地图片短信，不宣称 Google Voice 全功能等价：视频、音频附件、OCR、Google Photos 未实装，通话按用户要求暂缓。Windows 安装器沿用用户授权的未签名方式，线上更新清单仍必须通过 Ed25519 验签。
