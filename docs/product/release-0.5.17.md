# HelloDog 0.5.17

本次更新围绕双通道翻译、聊天窗口稳定性和费用统计进行优化。

- 每个聊天窗口可选择 **DeepSeek · deepseek-v4-pro** 或 **OpenAI · gpt-5.6-luna**，默认使用 DeepSeek。切换作用于后续翻译；正在处理的任务保留原通道，避免重复处理和扣费。
- 统一两个通道的发送前预览、译文恢复、目标语言和问句翻译检查；客户端显示总字符余额。
- 修复聊天页刷新后的空白显示和 WhatsApp 左侧列表拖动问题，改善窗口切换和异常后的恢复。
- 移除旧备注入口及不必要的客户端流水展示，简化主页和侧边导航；版本与更新集中在设置中，提供官网和重启入口。
- 优化通知面板和更新提示。通知面板使用不透明背景，更新状态区分“有新版本”和“已是最新版本”。
- 后台分别展示 DeepSeek、OpenAI 费用与合计，金额按两位小数展示，计算保留原始精度；区分调用费用、官方账单和账户余额，明确显示同步时间与未取得的数据。
- 稳定版包含此前 Signal 发送状态和恢复修复，构建过程核对内核来源及所有打包文件，避免旧组件混入。

官方账单存在更新延迟，费用以同一账户、账期和时区核对。同步尚未完成时不会把缺失数据作为零费用；充值余额也不等同于本期支出。

Google Voice 继续使用内嵌官方页面，并提供 HelloDog 翻译和独立窗口代理。第三方网页变更可能需要兼容更新；视频、音频附件、OCR、Google Photos 和通话能力不在本次新增范围内。

Windows 安装器沿用当前发行方式；更新清单签名和安装包完整性校验继续保留。
