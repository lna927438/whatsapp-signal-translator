# HelloDog 0.5.2-beta.6 本地验收记录

本轮只生成本地测试版本，没有上线、部署云端或运行安装程序覆盖现有账号。官方桌面组件来自 Signal Desktop v8.27.0，固定提交 `1a1d65153be546836d5948cb50493d4d1d293d02`。这是 HelloDog 修改后的构建，不是 Signal 官方发行包。

## 已实现并完成本地验证

- 原 Signal 聊天界面可选择、拖放、粘贴附件，显示图片，播放音频和视频，保存附件，插入表情及录制语音。录音在本机转换为 WAV。媒体草稿与发送任务保留附件编号，重开后可以恢复。
- 同一发送任务的重复点击和重试复用原任务；相同文字的不同消息分别处理。纯表情和纯附件跳过翻译。翻译失败保留消息，不增加每条消息的审核面板。
- 官方桌面源码和 Windows 原生依赖已完成编译；实际关联二维码已显示。官方窗口可嵌入 HelloDog、随聊天区域调整大小，并在其他面板打开时隐藏。
- 用真实 Signal 核心启动两个独立测试窗口，验证重复打开合并、独立数据目录、前后台切换、正常退出及重开使用原目录。尚未关联手机，因此这里的恢复验证不等于真实聊天记录和待发消息恢复。
- 发送翻译放入官方持久化发送队列，译文和原文关联写入成功后才继续原生发送。翻译超时、保存失败、消息被删除时不直接放行原文。入站译文采用单独显示层，并复用原请求。
- 182 项自动回归全部通过；浏览器已验证真实图片显示、音视频播放进度、960 像素窗口布局和合成录音转换。自动测试未给真实联系人发消息，也没有执行真实扣费或通话。

## 当前限制

1. 完整版需要手机单独关联；不会把原 signal-cli 数据库直接交给官方核心，也不把原客户端历史冒充为迁移后的历史。
2. 自动翻译目前覆盖普通文字和媒体说明。带富文本范围、提及和编辑的消息保留官方发送行为，尚未实现范围随翻译重排，不能作为翻译全功能验收通过。
3. 原客户端的贴纸、GIF 搜索和实时通话依靠“Signal 完整版”使用。原客户端新增的媒体收发尚需真实对端验收。
4. 官方原生安全码变更、验证码等必要交互继续保留；不会额外要求用户逐条审核正常消息。
5. 未连接手机和指定测试联系人之前，不宣称媒体已送达、扣费已经对账或通话已成功。

## 本地实测入口与证据

启动测试版时使用 `--isolated-test`，数据写入 `%APPDATA%/HelloDog-test-beta6`。正式安装的数据目录不变。测试账号需要登录 HelloDog，再从 Signal 页面选择“打开 Signal 完整版”并用手机扫码。

当前证据位于仓库的 `verification` 目录：`beta6-regression-final.log`、`beta6-media-ui-result.json`、`beta6-voice-result.json`、`native-integration/result.json` 和 `native-integration/packaged-result.json`。这些测试报告与真实手机验收记录分开保存。

源码来源：[Signal Desktop v8.27.0](https://github.com/signalapp/Signal-Desktop/tree/v8.27.0)。修改后的对应源码、许可证及构建脚本随本地测试产物提供。
