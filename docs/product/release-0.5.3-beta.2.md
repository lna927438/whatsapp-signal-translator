# HelloDog 0.5.3-beta.2 本地测试版

2026-09-12。本轮只生成本地测试文件，未发布安装包、网站、管理后台、云端接口或数据库更新。

## 本轮改动

1. **设置与重启**：侧栏设置改为齿轮图标；增加独立的“重启软件”按钮，菜单也有重启入口。重复点击只执行一次。先保存设置、草稿、原翻译请求及发送记录，再退出并启动；保存失败会停止重启并恢复按钮。录音、通话、未保存的附件仍在使用时，会保留现场并说明原因。
2. **统一安全刷新**：右键菜单、F5、Ctrl+R 进入同一刷新流程。空闲时刷新聊天；草稿、媒体或任务正在处理时先保存和检查连接，不直接销毁页面。超时会结束等待，不再永久转圈。
3. **发送与翻译等待**：单条翻译有总等待上限，交互任务优先于历史扫描；重试先查询该条原请求，避免被其他待确认请求拖住。翻译失败释放等待，正常发送不增加人工审核。
4. **历史与扣费**：同一消息保留第一次翻译的上下文、语气、术语和请求编号。联系人改名、修改默认语气、重开和缓存恢复不会创建替代请求；不同消息仍独立处理。记录保留原扣费结果，并另外显示“本次缓存恢复”。
5. **翻译质量**：低置信度内容交给服务自动识别；增加对目标语言、空译文、号码、链接和术语的检查。账号及联系人可分别保存自然/商务语气和术语，支持 TXT/JSON 导入、撤销。本地修正可复制、恢复原译文；单条重译可另选语气，明确作为新的翻译操作。
6. **快捷回复**：支持搜索；补齐官方 Signal 桌面组件的输入接入。只填入当前对话的空输入框，使用原生编辑器保存草稿，不直接发送，也不覆盖已有文字、emoji 或正在编辑的消息。
7. **本机数据保护**：草稿、发送任务、翻译记录、译文缓存和旧版 Signal 历史在下一次写入时使用本机系统加密，并按顺序写入、替换文件。无法解密或保存失败时不会把原账本当成空数据。
8. **窗口与性能**：保存窗口位置和最大化状态；重开时将离屏窗口移回现有屏幕范围。增加账号切换 p95、按账号数量区分的内存观察和官方 Signal 子进程采样；数据来自实际运行，不预填达标结果。

## 验证范围

- 265 项完整自动化回归通过，无失败或跳过；测试覆盖旧版本记录恢复、20 条连续消息按序发送、设置隔离、桥接超时、快捷回复防覆盖、保存失败和更新下载。结果见本版随附的 release-manifest.json。
- HelloDog 主进程、Vue 界面、测试工程与固定版本 Signal 全源码类型检查，以及两者生产构建均须通过后才交付。
- 已在独立测试目录执行真实进程重启：旧 HelloDog 和 Signal 退出，新 HelloDog 使用同一目录，系统加密草稿可恢复；官方组件完成 20 次刷新响应。
- 实际界面检查覆盖 1366×768、1280×720、960×620 的按钮可见性、术语保存/撤销、重启失败后的输入保留，以及收起后的图标入口。
- Signal 官方核心仍固定为 8.27.0。编译和组件启动不代表真实手机关联、联系人媒体双向收发或通话全部验收通过。
- 本轮没有向真实联系人发送消息或拨打电话，也没有产生真实 API 付费或修改线上字符余额。

## 使用与兼容

安装包：HelloDog Setup 0.5.3-beta.2.exe。对应源码、许可与校验清单随包提供。

安装前先从托盘退出旧版。更新后仍使用原 HelloDog 账号目录。也可使用同目录的 Start isolated test.cmd 在独立目录测试，需要重新登录和关联测试账号。

本版开始写入加密记录，旧的 beta.1/0.5.2 不支持读取这种格式。应用内更新已阻止直接降级；如需恢复，应使用支持同一数据格式的版本。加密记录绑定当前 Windows 用户，复制到另一 Windows 用户不能直接解锁。旧记录在下一次写入时迁移，并非安装后立即全部转换。

安装包为未签名的本地测试版，没有自动上传或替换正式下载。
