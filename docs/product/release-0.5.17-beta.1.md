# HelloDog 0.5.17-beta.1 — 本地升级验收

日期：2026-09-22。仅供本地验收，未发布、未安装覆盖正在使用的客户端、未修改线上账本或上传新密钥。

## 本次改动

- WhatsApp、Signal、Google Voice 每个账号窗口独立保存 DeepSeek / OpenAI 选择。切换只影响新翻译；正在处理、待核对、重试的消息沿用首次通道及编号，不自动换通道重复提交。
- 通道可用性以服务器配置为准。不可用的通道会显示原因；服务临时停用时先核对旧请求回执，防止重复扣费。切换 Google Voice 通道不重新加载网页或改动代理。
- 若仍使用旧的个人 DeepL/Google 配置，云端按钮会禁用并提示先在设置中选择 HelloDog 云端。旧配置保留，不会把明确选择 OpenAI/DeepSeek 的请求悄悄发往个人服务；设置切回云端后重新检测可用通道。
- 新 OpenAI 密钥通过本机真实 API、隔离账本和后台汇总联调。修正数量、中文量词、单价关系的通用翻译要求；疑问句仍只翻译，不由 AI 回答。
- 客户端只显示总余额与总用量；后台分别统计 OpenAI、DeepSeek 的调用、Tokens、回执计价费用及合计。失败调用产生的服务商费用与用户字符扣费分开记录。
- 移除客户端联系人备注、账号备注、红色备注及对应接口。新版首次启动清理旧备注字段和两个指定的备注文件；保留账号名称、官方联系人名称、聊天、草稿、代理、语言设置和历史计费记录。
- WhatsApp 侧栏拖动适配不同页面布局，修复拖动中断、节点替换及恢复默认宽度后留白/线条问题。在线状态直接依据官方可见状态，不再依赖备注，也不虚构离线状态。
- 译文颜色增加预览、确定、取消；取消不保存。通道和颜色保存时切换窗口不会把结果写到其他窗口。
- 主页仅展示 WhatsApp、Signal、Google Voice，点击进入创建窗口流程。侧栏增加文字；移除客户端流水、重复入口与不必要的显示。
- 个人中心改用轻量总量读取，可见时每 30 秒同步，并响应余额变化事件。
- 通知面板不透明，只显示签名最新版本对应的通知。旧版本显示官网更新按钮；已是最新版时显示状态、不再显示更新按钮；检查失败时明确显示未知，不误报最新版。
- 增加翻译准备、缓存查询、余额核对期间的登录身份复核，阻止旧身份任务向新身份计费或回传内容。

## 已验证

- 完整隔离回归：1264 项通过，0 失败、0 跳过。最后的提示词改动另通过 168 项相关回归。
- 最后的个人服务兼容保护通过 28 项通道、身份、重试回归及 7 项界面测试，两种尺寸下的设置来回切换亦通过浏览器验收。
- 客户端主进程、界面、测试及管理后台类型检查通过。
- 客户端及后台本地构建通过；Worker 仅执行 dry-run 构建，没有发布。
- 真实 Chromium 验收：主页、两种窗口尺寸、通道/颜色保存失败及跨窗口竞态、通知、Google Voice 创建和代理流程；WhatsApp 四种布局拖动与恢复场景通过。使用合成页面，不连接真实聊天账号。
- 管理后台真实组件浏览器验收：OpenAI / DeepSeek 分项相加等于总计，待核算调用不算作零费用，官方账单单列；1440/960 宽度无横向溢出。金额为合成数据、无实际网络请求。
- 新 OpenAI 密钥的第二轮四条合成样本均返回正确方向的译文。共 102 字符、4 次调用、2610 Tokens；同请求重放没有额外调用或扣费。OpenAI 分项与总计一致，回执计价 USD 0.000598000000。
- 样本包括“你怎么看？”、“What is your point of view?”、时间/费用句，以及“Can you confirm 3 tickets for 25 dollars each?”。最后一条译文为“你能确认3张票，每张25美元吗？”。有限样本不代表所有语言与聊天情境均已完成真人验收。
- 构建产物核对：16 个应用输出文件与安装包内文件一致，Google Voice 内嵌桥接和 Signal 组件保留，旧外部 Google Voice 宿主未进入包，Electron 安全开关通过检查。

## 暂不上线的边界

1. 新密钥只保存在已批准的本机测试文件中，没有放入安装包、源码提交或云端。测试包连接当前正式服务时，OpenAI 会显示“尚未启用”；当前用户继续使用 DeepSeek。
2. 双通道服务代码和通知数据库迁移已完成，但迁移尚未应用到云端。后续正式启用时需统一安排服务端、数据库与客户端升级。
3. 普通 OpenAI API 密钥用于翻译；官方账单自动同步需要另行具备账单权限。当前已完成按 Token 回执及定价规则计算费用，不能把它称为已读取 OpenAI 官方账单。
4. 旧客户端 OpenAI 直连实现已移除，旧个人密钥的清理迁移继续保留。内部旧 transport 标识、历史财务记录和必要回滚资料仍保留，不能按字符串含 OpenAI 就删除；没有销毁云端历史部署或业务数据。
5. 安装包尚未安装。没有替用户登录、发送真实短信、改动真实聊天草稿或启动此包共享现有账号资料。
