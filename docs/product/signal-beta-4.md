# HelloDog 0.5.2-beta.4 本地测试说明

本轮处理 Signal 设置、联系人资料和聊天操作缺失，以及发送准备/核对卡住的问题。安装包只用于本地实测，没有发布官网或更新通道，没有部署服务端，没有运行覆盖安装。已安装账号的数据仅做读取诊断，本轮没有修改，也没有向真实联系人发送测试消息。

## 发送流程

实机恢复记录显示：同一段 WhatsApp 对话中，一条旧任务停在发送结果不明，另有两条已经生成译文的待发送任务。旧逻辑会阻塞整个对话，不是要求用户每条消息验证 Signal 身份。

- 去掉发送时额外等待云端账号查询的步骤，账号状态独立在后台刷新。付费翻译仍由服务端正常鉴权和结算。
- 未确认的旧消息只保护它自身，允许继续发送其他内容。不会把旧消息自动重新发送。
- WhatsApp 保存、翻译、设置读取和提交都有超时恢复；卡住后释放输入，保留原任务和草稿。普通进度不再创建核对浮层。
- Signal 保存一条消息后即可继续输入，后续任务按顺序翻译和发送。常规发送不要求逐条审核；用户主动开启的发送前预览仍可使用。
- 后台依据原回执更新发送结果；重开、断线、晚到回执都不会自动再次提交。无法证明成功时保留未知状态，不伪造成功。
- 不同原文即使翻译结果相同，也保持不同任务和请求编号。多个任务可能对应同一段可见文字时，不把一个消息回执套给另一个任务。
- 已确认结果与错误处理之间的竞争不会把成功任务退回未知。已经过期的限时消息任务不会重新翻译。

## Signal 本轮可用页面和操作

| 页面 | 已接入操作 |
| --- | --- |
| 设置 → 个人资料 | 查看名字、手机号、用户名、简介；修改名字和简介；通过文件选择更新头像 |
| 设置 → 通用、外观、聊天 | 查看关联设备；深色、浅色、跟随系统；消息字号；Enter 发送偏好；存档保持选项 |
| 设置 → 提醒、隐私、数据 | 通知、声音、隐藏名称；本设备已读回执；已屏蔽联系人及解除屏蔽；本地设置导出和恢复 |
| 联系人资料 | 头像、号码或用户名、简介；聊天搜索；静音及静音时长；存档；昵称和备注；聊天颜色；置顶；限时消息；安全码；屏蔽 |
| 群组资料 | 群说明、成员、共同群组跳转；按权限添加成员、修改限时消息；退出群组 |
| 聊天列表 | 联系人搜索；手机号和用户名新对话；备忘录；新建群组；已存档聊天；聊天文件夹 |
| 消息 | 原文和译文；发送、送达、已读状态；收到的图片预览及文件保存；搜索本机已保存的对话文字和链接 |

设置按 HelloDog 登录用户和 Signal 账号隔离。联系人同时有手机号、UUID、用户名时，静音、已读和存档沿用同一个联系人；消息及翻译请求身份不因别名合并而被重写。群聊只有全部已知收件人已读才显示已读，其他联系人的同时间回执不会串到当前消息。

限时消息在到期后清除本机保存的正文、译文、相关翻译缓存和附件。迟到的翻译不能把正文写回来。对账所需请求编号、字符数和扣费状态保留；这不代表服务端的既有日志或对方设备内容也被清除。

## 开源依据和当前范围

界面流程对照 [Signal Desktop 开源项目](https://github.com/signalapp/Signal-Desktop/tree/6aea489bd04f31f6070538ffdbcea9fcf492479d) 的设置、聊天文件夹和联系人资料实现。此次并未将完整 Signal Desktop 嵌入 HelloDog。

实际通信继续使用未经修改的 [signal-cli 0.14.7](https://github.com/AsamK/signal-cli/tree/82a2da59a8d32bb1638bbc3bdbb3cef8344a4fbb)，通过该版本公开的 [JSON-RPC](https://github.com/AsamK/signal-cli/blob/v0.14.7/man/signal-cli-jsonrpc.5.adoc) 和 [命令接口](https://github.com/AsamK/signal-cli/blob/v0.14.7/man/signal-cli.1.adoc) 接入功能。不是自行仿造 Signal 通信协议。原始许可、Java legal 文件、源码地址及对应源码压缩包继续随本地交付保留。

本版仍不等同于完整原版 Signal：语音/视频通话、主动发送附件、完整手机历史迁移和完整聊天备份尚未接入。手机号可见性、PIN、用户名/二维码管理等需要在手机端操作，页面有相应说明。设置备份只恢复本账号的外观、发送和通知等偏好，不恢复聊天、密钥或手机备份。媒体页只包含此设备已经接收和保存的附件。

## 实测重点

1. 在原来卡住的 WhatsApp 对话中发送一条新的内容，确认可以直接发送。旧的结果不明消息不会自动重发。
2. Signal 连续发送两条文字，第一条翻译时继续输入第二条；确认收件人、先后顺序和译文。
3. 打开 Signal 设置，改主题和字号；修改个人简介，再用手机核对。
4. 点击对方头像或名字，修改昵称、静音和存档；用隐藏手机号的联系人测试未读消除和新消息恢复存档。
5. 发送过程中切换网络或重开客户端，核对原任务结果；不要仅以输入框清空判定发送成功。

自动化、模拟界面及空白账号目录的真实进程检查不能替代本人手机和真实联系人双向收发验收。完整验证结果及安装包校验值见 release 中同版本验收记录和 manifest。
