# HelloDog 0.5.23-beta.1 本机候选

本轮修复语音翻译仍要求选择下载文件、译文落在气泡外，以及“禁止发送中文”开关没有真正控制发送的问题。基于 0.5.22 开发；未公开发布，不更改服务器计费规则。

## 语音

- 点击原消息中的“转为中文”，读取所选消息的音频，英文与中文放在原语音气泡内下方。消息操作不再打开音频文件选择器。
- WhatsApp 使用消息的准确标识取得该消息模型、官网媒体缓存或原生读取器。opaque 标识仅使用该行绑定的唯一消息模型，不根据联系人名字或最近播放的音频推断。
- Signal 使用原生附件队列取得该消息的语音，附件加载完成后继续处理；下载新增的本地路径不会误使消息身份失效。
- Telegram、Google Voice 读取消息自己的播放器；Google Voice 通过固定的页面程序读取已确认的音频，只返回规范化音频数据。
- Telegram、Google Voice 的部分语音首次加载需要短暂启动所选语音的官网播放器，随后自动暂停并读取；已有音频数据时无需这一步。这段首次加载体验仍待真实账号验证。
- 切换会话、替换语音、撤回、删除或读取超时会停止旧任务继续识别。失败在原气泡内重试，不选择其他消息代替。原语音保留。
- 音频读取、解码和渲染有独立的超时保护，关闭解码器不再阻塞按钮恢复；Google Voice 的旧读取标记会随取消清除，避免重试始终显示忙碌。
- 语音上限仍为 5 分钟 / 20 MB；点击前不识别、不请求翻译。保留原有消息级请求标识、重复点击合并及中英双译校验。
- Signal 已加载语音沿用 0.5.22 的计费身份，首次加载完成后的身份与重启后相同。沿用算法包含附件路径，迁移附件文件位置后仍可能形成新的身份，不能承诺跨文件迁移重复处理不产生费用。

## 中文发送

- 开启“禁止发送中文”：中文草稿可先翻译，实际要发出的内容仍含汉字则拦截，包括图片说明、混合文本和中文/日文目标语言。
- 关闭：含中文的原稿直接发送，不自动翻译，不产生该次翻译扣费；原有空格、换行保持原样。
- 设置页变更同步到已有窗口；窗口级设置可以再次覆盖。发送途中改变设置会保留原稿并要求重新发送，避免旧任务沿用过期规则。
- Signal 在附件上传、发送队列等待结束后，再核对当前设置与原消息；保存开关前等待原生程序确认旧任务失效。Google Voice 的页面也需确认旧任务取消后才保存设置。已经交给官方发送程序的消息无法撤回。
- 已发送或结果不明的任务不自动重发。

## 验证范围

用户反馈截图来自其他电脑，本机目前不能进行真实账号验收。自动回归和 Chromium/Electron 夹具用于验证身份、读取、取消、布局及发送规则；不代表官方账号、网络和接收端已验收。具体测试结果保存在本轮交付清单中。

## 页面接口依据

WhatsApp 兼容代码核对了维护项目记录的当前页面媒体接口：[whatsapp-web.js 媒体读取](https://github.com/pedroslopez/whatsapp-web.js/blob/main/src/util/Injected/Utils.js)、[WA-JS 媒体读取](https://github.com/wppconnect-team/wa-js/blob/main/src/chat/functions/downloadMedia.ts)。这些属于官网内部实现，会随页面版本变化，不能当作永久稳定的公开 API。
