# Release approval

Effective user instruction: 2026-09-10, after the HelloDog 0.5.1 release started.

Complete optimization, testing and reviewable previews before publishing. Require the user's explicit approval of the next release before merging into main, creating a release/windows-v* branch, starting a production deployment, or replacing public installer/metadata objects. Earlier blanket authorization does not apply to future releases.

Development branches and read-only checks remain authorized. Keep proposed changes there until the user approves release. Do not treat a completed test run as release approval.
