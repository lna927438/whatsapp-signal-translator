# HelloDog 翻译器

**用于 WhatsApp、Signal 与 Telegram 的 Windows 聊天翻译软件。** 在同一工作台切换独立账号，查看文字译文，将回复翻译成对方的语言，并按需把语音显示为英文和中文。

HelloDog is a Windows desktop translator for WhatsApp, Signal, and Telegram, with separate account sessions, incoming and outgoing text translation, and on-demand English/Chinese voice transcripts.

[HelloDog 官网](https://hellodog.net/) · [Windows 官方下载](https://hellodog.net/download) · [使用指南](https://hellodog.net/guide) · [更新记录](https://hellodog.net/updates)

## 开始使用

1. 下载 Windows x64 安装程序；升级前从“文件 → 退出”正常退出 HelloDog。
2. 使用 HelloDog 账号登录；首次注册需要验证邮箱。
3. 在主页添加 WhatsApp、Signal 或 Telegram，按对应平台提示登录或关联设备。
4. 设置双方语言及翻译通道，按需要启用接收翻译、群组翻译和历史消息翻译。
5. 使用连接页的翻译测试检查服务；真实收发请先与自己或同意测试的联系人核对。

各平台的聊天账号与 HelloDog 登录账号分别管理。WhatsApp 与 Telegram 支持逐账号代理。正式升级沿用已有数据目录；独立测试窗口的数据不会自动合并到正式版。

## 语音与 Telegram 的使用范围

语音只在点击后处理，不自动播放或发送识别文字。识别在本机完成，需要翻译的文字使用当前窗口通道；完成后可在原语音下方查看英文与中文。无法直接读取的语音可先从官方页面下载，再选择文件。此功能不包含实时通话翻译。

Telegram 的普通文字、图片选择和聊天记录继续使用官方网页。带文字的编辑保存、定时或付费附件等特殊发送方式暂不支持翻译放行，遇到提示请保留草稿并改用普通发送。首次空会话或翻看旧历史时，回执可能需要人工核对。

选择“我已核对，尚未发送”只解除原任务的待确认状态，并尽可能恢复原稿；不会自动再次发送，也不会创建新的翻译任务。已有新草稿不会被覆盖。

## 字符用量、缓存与隐私

- 普通文字按成功翻译的原文计算字符，首尾空白不计，不按译文或附带上下文长度收费。
- 同一翻译请求成功后只结算一次。恢复已有译文缓存不为同一个已完成请求再次扣减字符；不同消息即使文字相同，也可能是不同请求。
- 语音原文已是目标语言时直接复用。需要分别译成英文和中文时会产生各自的翻译用量；已完成结果重复查看不新增翻译。
- 已确认失败且未结算的请求不扣减字符。结果待确认时继续核对原请求；更改原文、语言或主动重新翻译可能产生新请求。
- 客户端与[官网用户中心](https://hellodog.net/account)可查看余额和用量。套餐与在线支付暂未开放，字符额度目前由管理员添加。
- 启用云端翻译时，原文及必要上下文会发送至 HelloDog 云端和翻译服务商处理。请按需开启。

## 遇到问题时

翻译完成、平台发送成功和对方已读是不同状态，请按平台回执核对。网络、账号限制或平台网页变化可能影响使用。翻译结果需要结合上下文判断。

先查看[使用指南](https://hellodog.net/guide#troubleshooting)。反馈请提供客户端版本、Windows 版本、平台、发生时间与复现步骤；截图请遮住私人消息、二维码和凭据。
